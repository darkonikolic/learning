# Create cheatsheet

## Output

A short, dense reference — tables, syntax, and the few things worth memorizing.

## Rules

- Only condense what the learner already understands; this is recall support, not first teaching.
- Prefer tables and code snippets over prose.
- Include the common gotcha for each item where relevant.
- Keep it to one screen where possible; cut anything not used in practice.
