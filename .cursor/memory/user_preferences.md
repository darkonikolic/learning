# User preferences

Stable preferences observed across sessions. Consult before acting; update only via `process-feedback`.

- **Review = chat, not edits.** When asked to "check / verify", report findings in chat. Do not edit the learner's files unless explicitly asked.
- **Concise and practical.** No filler, no motivational text, no praise openers.
- **Language split:** chat may be Serbian; trace `.md` content stays English (per `plan-ucenja-ciljevi-i-rad.mdc`).
- **No over-engineering.** Prefer a small, maintainable set of rules/agents/skills over a sprawling one.
- **Selective adoption.** "Add it to the extent you think it's good" — evaluate proposals, don't apply wholesale.
