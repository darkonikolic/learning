# Unit 1 — Scope: reliability vocabulary you can defend

Outcome: stop treating resilience as slogan patterns—articulate **how systems degrade and recover measurably**.

## Core lenses

```
Timeout budgets cascading honestly (reject uniform deep timeouts multiplying queue hell without defence)
Backoff + jitter + capped retries (amplify vs soothe dependency failure consciously)
Circuit breakers & bulkheads (blast radius shrinking—name what you isolate)
Graceful degradation & brownouts (partial product value vs brittle all-or-nothing)
SLIs / SLOs / error budgets (translate percentages to allowable minutes / money stories)
Operational signals tying metrics/logs/traces to user pain—not vanity dashboards only
```

## Practice backbone

Reuse **Gateway → Symfony → Go → Redis → Postgres → Queue** tabletop when Redis/DB/worker degrade—articulate behaviours per surface.
