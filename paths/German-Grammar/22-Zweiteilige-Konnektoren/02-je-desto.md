# je...desto / umso — Poseban red reči

**Nivo:** B2

Konstrukcija je...desto (ili je...umso) izražava **proporcionalni odnos**: sa promenom jedne veličine proporcionalno se menja druga. Oba dela moraju imati **komparativ**. Red reči je potpuno drugačiji od ostalih dvočlanih veznika.

---

## Struktura i red reči

```
Je [komparativ] ... [glagol na kraju],  desto/umso [komparativ] [glagol] [subjekt].
   ↑ sporedna rečenica                            ↑ inverzija u glavnoj rečenici
```

**Ključno:**
- **je** uvodi **sporednu rečenicu** → glagol ide **na kraj**
- **desto/umso** uvodi **glavnu rečenicu** → **inverzija** (glagol na 2. mestu, subjekt iza glagola)

---

## Primeri sa analizom

### Primer 1 — osnovna struktura

```
Je mehr du lernst, desto besser wirst du.
→ Što više učiš, to bolji postaješ.

Je [mehr] du [lernst],    desto [besser] [wirst] [du].
   kompar.  glagol kraj          kompar.  glagol  subj.
             ↑ sporedna                   ↑ inverzija
```

### Primer 2 — sa složenijim glagolom

```
Je früher du aufstehst, umso mehr Zeit hast du.
→ Što ranije ustaneš, to više vremena imaš.
```

### Primer 3 — negativna proporcija

```
Je weniger du schläfst, desto müder wirst du.
→ Što manje spavaš, to umorniji postaješ.
```

### Primer 4 — sa modalnim glagolom

```
Je mehr du übst, desto besser kannst du spielen.
→ Što više vežbaš, to bolje možeš da sviraš.
```

### Primer 5 — sa imeničkim komparativom

```
Je mehr Geld er verdient, umso mehr gibt er aus.
→ Što više novca zarađuje, to više troši.
```

## desto vs umso — postoji li razlika?

| | Desto | Umso |
|---|---|---|
| Značenje | isto | isto |
| Upotreba | malo češće u govoru | malo češće u pisanom |
| Greška? | oba su ispravna | oba su ispravna |

> Slobodno koristiti oba — nema gramatičke razlike. Umso zvuči nešto formalnije.

---

## Česte greške u redu reči

### Greška 1: Glagol nije na kraju u je-delu

```
✗ Je mehr du lernst schnell, desto besser ist es.
✓ Je schneller du lernst, desto besser ist es.
→ Što brže učiš, to bolje je.
```

### Greška 2: Nema inverzije posle desto/umso

```
✗ Je mehr du lernst, desto du wirst besser.
✓ Je mehr du lernst, desto besser wirst du.
```

### Greška 3: Komparativ nedostaje

```
✗ Je viel du lernst, desto gut wirst du.
✓ Je mehr du lernst, desto besser wirst du.
→ Oba dela MORAJU imati komparativ.
```

### Greška 4: Mešanje sa Konjunktivsatzом

```
✗ Je mehr du lernst, desto besser du wirst.
✓ Je mehr du lernst, desto besser wirst du.
→ Posle desto: INVERZIJA, ne normalan red
```

## Lista čestih komparativa u ovoj konstrukciji

| Komparativ | Srpski | Primer |
|---|---|---|
| mehr | više | je mehr, desto besser |
| weniger | manje | je weniger, desto schlechter |
| früher | ranije | je früher, umso länger |
| später | kasnije | je später, desto müder |
| schneller | brže | je schneller, desto effizienter |
| länger | duže | je länger, desto schwieriger |
| größer | veće | je größer, desto teurer |
| mehr | više (kol.) | je mehr Übung, desto besser |

---

## Transformacija od normalne rečenice

Porast X → porast Y može se izraziti na više načina:

```
Wenn man mehr lernt, wird man besser.
→ Je mehr man lernt, desto besser wird man.

Mit mehr Übung kann man besser spielen.
→ Je mehr man übt, desto besser kann man spielen.
```
