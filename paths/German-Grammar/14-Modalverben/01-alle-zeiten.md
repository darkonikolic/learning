# Modalni glagoli u svim vremenima

**Nivo:** B1

Präsens modalnih glagola je obrađen u [../01-Präsens/08-modalni.md](../01-Präsens/08-modalni.md). Ovde su sva ostala vremena.

---

## können — moći

**Präteritum:** konnte / konntest / konnte / konnten / konntet / konnten

```
Ich konnte nicht schlafen.           Nisam mogao/la da spavam.
Als Kind konnte er gut schwimmen.    Kao dete, mogao je dobro da pliva.
```

**Perfekt:** `haben + gekonnt`
```
Ich habe das nicht gekonnt.          Nisam to mogao/la.
```
> Perfekt modalnih glagola se retko koristi bez infinitiva. S infinitivom → **doppelter Infinitiv**: Ich habe nicht kommen können.

**Konjunktiv II:** könnte / könntest / könnte / könnten / könntet / könnten
```
Könntest du mir helfen?              Mogao/la bi mi pomoći?
Das könnte funktionieren.            To bi moglo da funkcioniše.
```

**Futur I:** `werden + können`
```
Ich werde das schaffen können.       Moći ću to da ostvarim.
```

---

## müssen — morati

**Präteritum:** musste / musstest / musste / mussten / musstet / mussten

```
Ich musste früh aufstehen.           Morao/la sam rano da ustanem.
Sie musste zum Arzt gehen.           Morala je kod lekara.
```

**Perfekt:** `haben + gemusst`
```
Ich habe das gemusst.                Morao/la sam to.
```
S infinitivom: Ich habe früh aufstehen müssen.

**Konjunktiv II:** müsste / müsstest / müsste / müssten / müsstet / müssten
```
Du müsstest mehr schlafen.           Trebalo bi da više spavaš.
Das müsste klappen.                  To bi trebalo da ide.
```

**Futur I:** `werden + müssen`
```
Sie wird das akzeptieren müssen.     Moraće to da prihvati.
```

---

## dürfen — smeti

**Präteritum:** durfte / durftest / durfte / durften / durftet / durften

```
Früher durften Kinder das nicht.     Ranije deca to nisu smela.
Er durfte nicht rauchen.             Nije smeo da puši.
```

**Perfekt:** `haben + gedurft`
```
Das haben wir nicht gedurft.         To nismo smeli.
```

**Konjunktiv II:** dürfte / dürftest / dürfte / dürften / dürftet / dürften
```
Das dürfte nicht lange dauern.       To verovatno neće dugo trajati. (subjektivno)
Hier dürfte man eigentlich nicht parken. Ovde se zapravo ne bi smelo parkirati.
```

**Futur I:** `werden + dürfen`
```
Er wird das nicht dürfen.            Neće mu biti dozvoljeno to.
```

---

## wollen — hteti

**Präteritum:** wollte / wolltest / wollte / wollten / wolltet / wollten

```
Er wollte Arzt werden.               Hteo je da postane lekar.
Wir wollten verreisen, aber es regnete.  Hteli smo da putujemo, ali je padala kiša.
```

**Perfekt:** `haben + gewollt`
```
Das habe ich nie gewollt.            To nikad nisam hteo/la.
```

**Konjunktiv II:** wollte (= Präteritum — isti oblik)
```
Wenn ich wollte, könnte ich gehen.   Kad bih hteo/la, mogao/la bih da odem.
```

**Futur I:** `werden + wollen`
```
Er wird das nie wollen.              On to nikad neće hteti.
```

---

## sollen — trebati (tuđa obaveza)

**Präteritum:** sollte / solltest / sollte / sollten / solltet / sollten

```
Ich sollte um 8 Uhr kommen.          Trebalo je da dođem u 8. (rekli su mi)
Sie sollte das Paket abholen.        Trebala je da preuzme paket.
```

**Perfekt:** `haben + gesollt`
```
Das hätte ich nicht gesollt.         To nisam smeo/la da uradim.
```

**Konjunktiv II:** sollte (= Präteritum)
```
Du solltest mehr Sport treiben.      Trebalo bi da više vebaš.
```

**Futur I:** `werden + sollen`
```
Er wird kommen sollen.               Trebalo bi da dođe.
```

---

## mögen / möchten — voleti / želeti

**Präteritum mögen:** mochte / mochtest / mochte / mochten / mochtet / mochten

```
Als Kind mochte ich keinen Fisch.    Kao dete nisam voleo/la ribu.
Er mochte sie sehr.                  Mnogo mu se sviđala.
```

**möchten** nema Präteritum — za prošlu blagu želju koristi se *wollte*.

**Perfekt mögen:** `haben + gemocht`
```
Ich habe das nie gemocht.            To nikad nisam voleo/la.
```

**Konjunktiv II mögen:** möchte (standardni oblik) / mögte (ređe)

**Futur I:** `werden + mögen`
```
Das wirst du mögen.                  To ćeš voleti.
```

---

## Doppelter Infinitiv — s infinitivom u Perfektu

Kad modal ima infinitiv uz sebe, Perfekt se gradi s **doppeltem Infinitiv** (infinitiv + infinitiv modala na kraju):

```
Ich habe nicht kommen können.        Nisam mogao/la da dođem.
Er hat nicht schlafen müssen.        Nije morao da spava.
Sie hat das nicht machen dürfen.     Nije smela to da uradi.
Wir haben früher aufstehen wollen.   Hteli smo ranije da ustanemo.
```

> U sporednoj rečenici: *..., weil ich nicht kommen können habe.* (haben dolazi na kraj, IZA infinitiva)
