# Subjektivna upotreba modalnih glagola

**Nivo:** B2

Osim objektivne upotrebe (sposobnost, obaveza, dozvola), modalni glagoli se koriste i **subjektivno** — za iznošenje **pretpostavke, ocene ili čuvenog govora** govornika.

```
Objektivno: Er muss früh aufstehen.  (mora = obaveza)
Subjektivno: Er muss müde sein.      (mora biti = pretpostavljam)
```

---

## müssen — mora biti (sigurna pretpostavka)

Govornik je skoro siguran da je nešto tačno.

**Sadašnjost** (Infinitiv Präsens):
```
Das muss ein Fehler sein.            Mora da je greška.
Sie muss zu Hause sein — das Licht brennt.  Mora da je kod kuće — svetlo gori.
Er muss sehr klug sein.              Mora da je veoma pametan.
```

**Prošlost** (Infinitiv Perfekt: haben/sein + Partizip II):
```
Er muss das vergessen haben.         Mora da je zaboravio.
Sie muss früh angekommen sein.       Mora da je stigla rano.
Das muss ein Missverständnis gewesen sein.  Mora da je bio nesporazum.
```

---

## können — moguće je (mogućnost / nesigurnost)

Govornik smatra da je nešto moguće, ali nije siguran.

**Sadašnjost:**
```
Das kann sein.                       Moguće je. / Može biti.
Er kann krank sein.                  Možda je bolestan.
Das kann ein Fehler sein.            To možda jeste greška.
```

**Prošlost:**
```
Er kann das vergessen haben.         Možda je zaboravio.
Sie kann das gesagt haben.           Možda je to rekla.
```

---

## sollen — navodno, kaže se (čuveni govor)

Govornik prenosi ono što drugi govore — ne potvrđuje sam.

**Sadašnjost:**
```
Er soll sehr reich sein.             Navodno je veoma bogat. (kažu da je)
Das Buch soll sehr gut sein.         Kaže se da je knjiga veoma dobra.
Sie soll krank sein.                 Navodno je bolesna.
```

**Prošlost:**
```
Er soll das gesagt haben.            Navodno je to rekao.
Sie soll früher Sängerin gewesen sein.  Kaže se da je ranije bila pevačica.
```

---

## wollen — tvrdi da (sopstvena tvrdnja)

Subjekat **sam tvrdi** nešto o sebi — govornik može sumnjati u to.

**Sadašnjost:**
```
Er will das nicht gewusst haben.     Tvrdi da to nije znao.
Sie will unschuldig sein.            Tvrdi da je nevina.
```

**Prošlost:**
```
Er will dabei gewesen sein.          Tvrdi da je bio tamo.
Sie will das nicht gesehen haben.    Tvrdi da to nije videla.
```

> Razlika sollen vs wollen: *sollen* = drugi govore; *wollen* = on/ona sam/a tvrdi.

---

## dürfen — verovatno, opravdano je (oprezna pretpostavka)

Ukazuje na zaključak koji je logično opravdan — nešto što s pravom možemo pretpostaviti.

**Sadašnjost:**
```
Das dürfte stimmen.                  To verovatno stoji. / To bi trebalo da je tačno.
Das dürfte kein Problem sein.        To verovatno nije problem.
Er dürfte etwa 50 Jahre alt sein.    Verovatno ima oko 50 godina.
```

**Prošlost:**
```
Das dürfte schon bekannt gewesen sein.  To je verovatno već bilo poznato.
```

---

## mögen — mada, premda (ustupak)

Govornik prihvata da je nešto tačno, ali to ne menja zaključak.

**Sadašnjost:**
```
Das mag stimmen, aber es ändert nichts.  To može biti tačno, ali ništa ne menja.
Er mag Recht haben, trotzdem bin ich dagegen.  Možda ima pravo, ipak sam protiv.
```

**Prošlost:**
```
Das mag schwierig gewesen sein.      Možda je to bilo teško.
```

---

## Infinitiv Perfekt — za prošlost

Za subjektivne pretpostavke o prošlosti koristi se **Infinitiv Perfekt**:

| Pomoćni | Struktura | Primer |
|---------|-----------|--------|
| haben | haben + Partizip II | vergessen haben, gesagt haben |
| sein | sein + Partizip II | angekommen sein, gegangen sein |

```
Er muss krank gewesen sein.          Mora da je bio bolestan.
Sie kann das gehört haben.           Možda je to čula.
Er soll gewonnen haben.              Navodno je pobedio.
```

---

## Pregled subjektivnih značenja

| Modal | Subjektivno značenje | Srpski ekvivalent |
|-------|---------------------|-------------------|
| **müssen** | logična nužnost | mora biti, sigurno je |
| **können** | mogućnost | možda je, moguće je |
| **sollen** | čuveni govor | navodno, kažu da |
| **wollen** | sopstvena tvrdnja | tvrdi da |
| **dürfen** | opravdana pretpostavka | verovatno je |
| **mögen** | ustupak | mada, premda, možda i |
