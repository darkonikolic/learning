# Rečnik — Konjunktiv I Präsens

**Nivo:** B2

Najvažniji glagoli u Konjunktiv I Präsens. Oblici označeni sa ⚠ identični su sa Präsensom — u indirektnom govoru koristiti Konjunktiv II umesto njih.

Format: **glagol** · srpski · `ich / du / er / wir / ihr / sie`

---

## Pomoćni glagoli

**sein** · biti · `sei / seiest / sei / seien / seiet / seien`

**haben** · imati · `habe / habest / habe / haben ⚠ / habet / haben ⚠`

**werden** · postati/biti (fut.) · `werde / werdest / werde / werden ⚠ / werdet / werden ⚠`

---

## Modalni glagoli

**können** · moći · `könne / könnest / könne / können ⚠ / könnet / können ⚠`

**müssen** · morati · `müsse / müssest / müsse / müssen ⚠ / müsset / müssen ⚠`

**dürfen** · smeti · `dürfe / dürfest / dürfe / dürfen ⚠ / dürfet / dürfen ⚠`

**wollen** · hteti · `wolle / wollest / wolle / wollen ⚠ / wollet / wollen ⚠`

**sollen** · trebati (po tuđoj volji) · `solle / sollest / solle / sollen ⚠ / sollet / sollen ⚠`

> Modalni glagoli: oblici ich/er/sie su jasno različiti od Präsensa (er kann → er könne itd.), ali wir i sie su identični — zameni Konjunktivom II.

---

## Glagoli kretanja

**kommen** · doći · `komme / kommest / komme / kommen ⚠ / kommet / kommen ⚠`

**gehen** · ići · `gehe / gehest / gehe / gehen ⚠ / gehet / gehen ⚠`

**fahren** · voziti se · `fahre / fahrest / fahre / fahren ⚠ / fahret / fahren ⚠`

> Pažnja: fahren u Konjunktiv I ne menja vokal — fahre (ne: fähre). Promena vokala je osobina Konjunktiva II i Präsensa za du/er.

---

## Česti glagoli

**sagen** · reći · `sage / sagest / sage / sagen ⚠ / saget / sagen ⚠`

**machen** · praviti/raditi · `mache / machest / mache / machen ⚠ / machet / machen ⚠`

**wissen** · znati · `wisse / wissest / wisse / wissen ⚠ / wisset / wissen ⚠`

**sprechen** · govoriti · `spreche / sprechest / spreche / sprechen ⚠ / sprechet / sprechen ⚠`

**sehen** · videti · `sehe / sehest / sehe / sehen ⚠ / sehet / sehen ⚠`

**lesen** · čitati · `lese / lesest / lese / lesen ⚠ / leset / lesen ⚠`

**schreiben** · pisati · `schreibe / schreibest / schreibe / schreiben ⚠ / schreibet / schreiben ⚠`

**nehmen** · uzeti · `nehme / nehmest / nehme / nehmen ⚠ / nehmet / nehmen ⚠`

**geben** · dati · `gebe / gebest / gebe / geben ⚠ / gebet / geben ⚠`

---

## Napomena o nepravilnim glagolima

Konjunktiv I se uvek gradi od **infinitivnog korena** bez promena vokala:

| Glagol | Präsens er | Konjunktiv I er |
|---|---|---|
| fahren | fährt | fahre ✓ |
| nehmen | nimmt | nehme ✓ |
| sprechen | spricht | spreche ✓ |
| geben | gibt | gebe ✓ |
| lesen | liest | lese ✓ |

---

## Brzi pregled: er-oblici (najvažniji u indirektnom govoru)

| Glagol | Konj. I (er) | Präsens (er) | Razlika? |
|---|---|---|---|
| sein | sei | ist | ✓ da |
| haben | habe | hat | ✓ da |
| werden | werde | wird | ✓ da |
| können | könne | kann | ✓ da |
| müssen | müsse | muss | ✓ da |
| kommen | komme | kommt | ✓ da |
| sagen | sage | sagt | ✓ da |

> Svi er-oblici regularnih glagola završavaju na **-e** → uvek su različiti od Präsensa (koji završava na -t). Za er-lice nema problema!
