# Konjunktiv I — Gramatika

**Nivo:** B2

Konjunktiv I je glagolski način koji se koristi za **indirektni govor** (indirekte Rede) — prenošenje tuđih reči bez ličnog stava. Tipičan je za pisani jezik: novine, zvanični izveštaji, literatura. U svakodnevnom govoru retko se čuje.

---

## Tvorba Konjunktiva I

Konjunktiv I se gradi od **korena infinitiva** + nastavci:

| Lice | Nastavak | Primer: lernen |
|---|---|---|
| ich | -e | lerne |
| du | -est | lernest |
| er/sie/es | -e | lerne |
| wir | -en | lernen |
| ihr | -et | lernet |
| sie/Sie | -en | lernen |

> **Problem:** Oblici wir i sie/Sie su **identični** Präsensu — zbunjuju čitaoca. Tada koristimo Konjunktiv II ili würde+Infinitiv.

---

## Konjugacija: sein (jedini koji se zaista razlikuje)

**sein** je najvažniji glagol u Konjunktiv I — jedini čiji su svi oblici jasno različiti od Präsensa:

**sein** · biti · `sei / seiest / sei / seien / seiet / seien`

```
ich sei          → ja budem (konj.)
du seiest        → ti budeš (konj.)
er/sie/es sei    → on/ona bude (konj.)
wir seien        → mi budemo (konj.)
ihr seiet        → vi budete (konj.)
sie/Sie seien    → oni/Vi budu (konj.)
```

---

## Konjugacija: haben

**haben** · imati · `habe / habest / habe / haben / habet / haben`

```
ich habe         → (= Präsens! → koristiti hätte)
du habest        → razlikuje se ✓
er habe          → razlikuje se ✓
wir haben        → (= Präsens! → koristiti hätten)
ihr habet        → razlikuje se ✓
sie haben        → (= Präsens! → koristiti hätten)
```

---

## Konjugacija: werden

**werden** · postati/biti · `werde / werdest / werde / werden / werdet / werden`

```
ich werde        → (= Präsens! → koristiti würde)
du werdest       → razlikuje se ✓
er werde         → razlikuje se ✓
wir werden       → (= Präsens! → koristiti würden)
ihr werdet       → (= Präsens! → koristiti würdet)
sie werden       → (= Präsens! → koristiti würden)
```

---

## Konjugacija glagola kretanja

**kommen** · doći · `komme / kommest / komme / kommen / kommet / kommen`

**gehen** · ići · `gehe / gehest / gehe / gehen / gehet / gehen`

**fahren** · voziti se · `fahre / fahrest / fahre / fahren / fahret / fahren`

> Pažnja: kod nepravilnih glagola sa prevokalavom (fahren, laufen...) Konjunktiv I **ne menja vokal** — to je razlika od Präteritumskonjunktivа (Konjunktiv II).

---

## Pravilo zamene: kada Konj. I = Präsens → Konj. II

Kada bi oblik Konjunktiva I bio isti kao Präsens (čime se gubi smisao indirektnog govora), novine i zvanični tekstovi automatski prelaze na **Konjunktiv II** ili **würde + Infinitiv**:

| Situacija | Pravilo | Primer |
|---|---|---|
| Konj. I = Präsens | → koristiti Konj. II | wir lernen → lernten ili würden lernen |
| Konj. II zvuči arhaično | → koristiti würde + Inf. | sie gingen (OK) / sie würden gehen |
| sein, modali | → uvek jasni oblici | er sei, er könne, er müsse |

```
Er sagte, er lerne viel.          → lerne ≠ Präsens (er lernt) ✓
Er sagte, sie lernten viel.       → lernten = Konj. II (jer lernten ≠ Präsens lernten! — wait)
```

> Praktično pravilo: **sein uvek Konjunktiv I** (sei). Za ostale — provjeri da li oblik izgleda kao Präsens.

---

## Primeri iz stvarnog jezika

```
Der Minister erklärte, die Lage sei ernst.
→ Ministar je izjavio da je situacija ozbiljna.

Der Zeuge sagte, er habe nichts gesehen.
→ Svedok je rekao da nije ništa video.

Die Wissenschaftler berichteten, das Experiment sei gelungen.
→ Naučnici su izvestili da je eksperiment uspeo.
```
