# Konjunktiv I — Indirektni govor

**Nivo:** B2

Indirektni govor (indirekte Rede) znači prenošenje tuđih reči — bez navodnika, sa promenom lica i glagolskog načina. U nemačkom pisanom jeziku (novine, izveštaji) standardno se koristi **Konjunktiv I**.

---

## Direktni → indirektni govor: promena zamenica

Zamenice se menjaju prema perspektivi govornika:

```
"Ich bin müde."           → Er sagte, er sei müde.
"Wir kommen morgen."      → Sie sagten, sie kämen morgen.
"Du hast recht."          → Er sagte, ich habe recht. / er sagte, sie habe recht.
```

---

## Tri vremenska oblika u indirektnom govoru

### 1. Präsens → Konjunktiv I Präsens

Direktno: **"Die Situation ist schwierig."**

```
Der Minister sagte, die Situation sei schwierig.
→ Ministar je rekao da je situacija teška.
```

### 2. Perfekt → Konjunktiv I Perfekt

Konjunktiv I Perfekt: **habe/sei + Partizip II**

Direktno: **"Ich habe das Dokument unterschrieben."**

```
Er sagte, er habe das Dokument unterschrieben.
→ Rekao je da je potpisao dokument.

Sie erklärte, sie sei früh angekommen.
→ Objasnila je da je stigla rano.
```

> Pravilo za izbor habe vs sei: isti kao u Perfektu — glagoli kretanja i promene stanja → **sei**, ostali → **habe**.

### 3. Futur → Konjunktiv I Futur

Konjunktiv I Futur: **werde + Infinitiv**

Direktno: **"Wir werden das Problem lösen."**

```
Der Sprecher sagte, sie werden das Problem lösen.
→ ali werden = Präsens! Zato:
Der Sprecher sagte, sie würden das Problem lösen.
→ Portparol je rekao da će oni rešiti problem.
```

---

## Sa dass ili bez dass

Oba oblika su ispravna. Bez dass je češće u novinskom stilu (i elegantnije):

| Sa dass | Bez dass |
|---|---|
| Er sagte, **dass** er krank **sei**. | Er sagte, er **sei** krank. |
| Sie berichtete, **dass** das Projekt **gelungen sei**. | Sie berichtete, das Projekt **sei gelungen**. |

> Sa dass → glagol na **kraju** rečenice (red reči sporedne rečenice).
> Bez dass → glagol na **2. mestu** (red reči glavne rečenice, ali Konjunktiv I).

## Tabela svih transformacija

| Direktni govor | Indirektni govor | Vreme |
|---|---|---|
| "Ich lerne Deutsch." | Er sagt, er lerne Deutsch. | Konjunktiv I Präsens |
| "Ich habe gelernt." | Er sagt, er habe gelernt. | Konjunktiv I Perfekt |
| "Ich werde lernen." | Er sagt, er werde lernen. | Konjunktiv I Futur |
| "Ich war krank." | Er sagt, er sei krank gewesen. | Konjunktiv I Plusq. |

## Glagoli koji uvode indirektni govor

```
sagen     → Er sagte, ...
erklären  → Sie erklärte, ...
berichten → Die Zeitung berichtete, ...
betonen   → Der Chef betonte, ...
behaupten → Er behauptete, ...
meinen    → Sie meinte, ...
antworten → Er antwortete, ...
mitteilen → Das Ministerium teilte mit, ...
```

---

## Konjunktiv I u novinama — primeri

```
Der Außenminister erklärte, die Lage sei ernst, aber kontrollierbar.
→ Ministar spoljnih poslova je izjavio da je situacija ozbiljna, ali pod kontrolom.

Laut dem Bericht habe das Unternehmen Gewinne erzielt.
→ Prema izveštaju, kompanija je ostvarila profit.

Die Sprecherin teilte mit, man werde alle Möglichkeiten prüfen.
→ Portparolka je saopštila da će se ispitati sve mogućnosti.
```

---

## Konjunktiv I (neutralno) vs Konjunktiv II (sumnja/distanca)

Ovo je ključna razlika za B2:

| Konjunktiv I | Konjunktiv II |
|---|---|
| Neutralno prenošenje tuđih reči | Govornik izražava **sumnju** ili **distancu** |
| Novinski stil, izveštaji | Govorni jezik, ironija, skepsa |
| Er sagte, er **sei** krank. | Er sagte, er **wäre** krank. |
| Prihvata se kao verovatna informacija | Implicira: „Sumnjam u to." |

```
Er behauptete, er sei zu Hause gewesen. (neutralno — prenos)
→ Tvrdio je da je bio kod kuće.

Er behauptete, er wäre zu Hause gewesen. (sa distancom)
→ Tvrdio je da je bio kod kuće. (ali ja sumnjam u to)
```
