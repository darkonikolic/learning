# Indirektna pitanja (Indirekte Fragesätze)

**Nivo:** B1


Indirektno pitanje je pitanje koje je **ugrađeno unutar druge rečenice** — nije samostalno. Ne stoji sam, već dolazi posle glagola tipa *wissen*, *fragen*, *sagen*, *erklären*...

---

## Osnovna razlika: direktno vs. indirektno pitanje

| Direktno pitanje | Indirektno pitanje |
|---|---|
| Wo wohnst du? | Ich weiß nicht, **wo du wohnst**. |
| Wann kommt er? | Kannst du mir sagen, **wann er kommt**? |
| Ist er müde? | Ich frage mich, **ob er müde ist**. |

---

## Tri ključna pravila

### 1. Glagol uvek na KRAJU

U indirektnom pitanju glagol ide na **poslednje mesto** — nema inverzije:

```
Direktno:   Wo wohnst du?        (inverzija: wohnst ispred du)
Indirektno: Ich weiß, wo du wohnst.  (du wohnst — normalan red, glagol na kraju)
```

### 2. Nema inverzije

Subjekat dolazi ispred glagola, bez inverzije:

```
GREŠKA:    Ich weiß, wo wohnst du.
ISPRAVNO:  Ich weiß, wo du wohnst.
```

### 3. Nema upitnika (osim ako je cela rečenica pitanje)

```
Ich weiß nicht, wo er wohnt.        → tačka (izjavna rečenica)
Weißt du, wo er wohnt?              → upitnik (cela rečenica je pitanje)
```

---

## Dva tipa indirektnih pitanja

### Tip 1: W-pitanja → W-reč uvodi indirektno pitanje

```
W-reč + Subjekt + ... + Glagol(kraj)
wo     + du     +     + wohnst
```

### Tip 2: Ja/Nein pitanja → ob uvodi indirektno pitanje

```
ob + Subjekt + ... + Glagol(kraj)
ob + er      +     + kommt
```

---

## Glagoli koji uvode indirektno pitanje

| Glagol | Srpski | Primer |
|---|---|---|
| wissen | znati | Ich weiß nicht, wo er wohnt. |
| fragen | pitati | Er fragt, wann der Zug kommt. |
| verstehen | razumeti | Ich verstehe nicht, warum das passiert. |
| erklären | objašnjavati | Sie erklärt, wie das funktioniert. |
| sagen | reći | Kannst du mir sagen, wo das ist? |
| wissen wollen | hteti da zna | Er will wissen, ob das stimmt. |
| sich fragen | pitati se | Ich frage mich, ob er kommt. |
| zeigen | pokazati | Zeig mir, wie man das macht. |

---

## Pregled strukture

```
[Glavna rečenica] + [W-reč / ob] + [Subjekt] + [...] + [Glagol(kraj)]
Ich weiß nicht,     wo             du                   wohnst.
Er fragt,           wann           der Zug               kommt.
Sie erklärt,        wie                                  man das macht.
Ich frage mich,     ob             er                   müde ist.
```
