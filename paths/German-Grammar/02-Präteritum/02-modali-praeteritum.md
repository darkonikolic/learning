# Modalni glagoli u Präteritumu

**Nivo:** A2

Modalni glagoli se u **govoru uvek koriste u Präteritumu**, nikad u Perfektu.

```
Ich musste gehen.        ✓ (govor i pisanje)
Ich habe gemusst.        ✗ (ne koristi se u praksi)
```

---

## Konjugacija — svih 6 modalnih

**können** (Präteritum) · mogao/la sam · `konnte / konntest / konnte / konnten / konntet / konnten`

**müssen** (Präteritum) · morao/la sam · `musste / musstest / musste / mussten / musstet / mussten`

**dürfen** (Präteritum) · smeo/la sam · `durfte / durftest / durfte / durften / durftet / durften`

**wollen** (Präteritum) · hteo/la sam · `wollte / wolltest / wollte / wollten / wolltet / wollten`

**sollen** (Präteritum) · trebao/la sam · `sollte / solltest / sollte / sollten / solltet / sollten`

**möchten→mochte** (Präteritum) · voleo/la sam · `mochte / mochtest / mochte / mochten / mochtet / mochten`

> **Uočiti:** ich = er/sie/es (nema nastavka), isto kao u Präsensu.
> Umlaut nestaje: können → **konnte** (ne könnnte), müssen → **musste**, dürfen → **durfte**.

---

## Primeri po glagolu

### können (mogao/la sam)

```
Ich konnte nicht schlafen.         → Nisam mogao/la da spavam.
Er konnte Englisch sprechen.       → Mogao je da govori engleski.
Konntest du kommen?                → Jesi li mogao/la da dođeš?
Wir konnten nichts tun.            → Nismo mogli ništa da učinimo.
```

### müssen (morao/la sam)

```
Ich musste früh aufstehen.         → Morao/la sam rano da ustanem.
Sie musste zum Arzt gehen.         → Morala je da ide kod lekara.
Er musste hart arbeiten.           → Morao je da radi naporno.
Wir mussten warten.                → Morali smo da čekamo.
```

### dürfen (smeo/la sam)

```
Ich durfte nicht ausgehen.         → Nisam smeo/la da izađem.
Als Kind durfte ich spät bleiben.  → Kao dete smeo/la sam da ostajem kasno.
Er durfte nicht rauchen.           → Nije smeo da puši.
```

### wollen (hteo/la sam)

```
Ich wollte Arzt werden.            → Hteo/la sam da postanem lekar.
Er wollte nicht kommen.            → Nije hteo da dođe.
Was wolltest du sagen?             → Šta si hteo/la da kažeš?
Wir wollten feiern.                → Hteli smo da slavimo.
```

### sollen (trebao/la sam)

```
Ich sollte das nicht tun.          → Nije trebalo da to radim.
Er sollte um 8 Uhr kommen.         → Trebalo je da dođe u 8.
Was sollte das bedeuten?           → Šta je to trebalo da znači?
```

### möchten → mochte (voleo/la sam)

```
Ich mochte ihn sehr.               → Mnogo sam ga voleo/la.
Sie mochte keine Tomaten.          → Nije volela paradajz.
```

---

## Modali s infinitivom — red reči

Isto kao u Präsensu — modal na 2. mestu, infinitiv na kraju:

```
Ich musste jeden Tag arbeiten.
Er konnte die Aufgabe nicht lösen.
Konnten Sie mir helfen?
```

### U sporednoj rečenici

Modal ide na kraj, infinitiv ispred njega:

```
Ich weiß, dass er nicht kommen konnte.
Er sagte, dass sie gehen musste.
Weil ich schlafen wollte, ging ich früh.
```

---

## Präteritum modalnih vs Perfekt

U praksi se gotovo uvek koristi Präteritum:

| Präteritum (normalno) | Perfekt (retko, formalno) |
|-----------------------|--------------------------|
| Ich musste gehen. | Ich habe gehen müssen. |
| Er konnte kommen. | Er hat kommen können. |
| Sie wollte bleiben. | Sie hat bleiben wollen. |

Perfekt modalnih postoji ali je stilski nespretno — izbegavaj ga.
