# Präteritum — Gramatika

**Nivo:** A2–B1

Präteritum je prošlo vreme koje se koristi pretežno u **pisanom jeziku** — pripovedanje, novine, knjige, formalni tekstovi.

U govoru se koristi Perfekt. Izuzetak: **sein, haben i modalni glagoli** — ti se uvek koriste u Präteritumu, čak i u govoru.

---

## Kada se koristi

| Kontekst | Vreme | Primer |
|----------|-------|--------|
| Govorni jezik (prošlost) | **Perfekt** | Ich habe gegessen. |
| Pisani jezik, naracija | **Präteritum** | Er aß und schwieg. |
| sein/haben/modali uvek | **Präteritum** | Ich war müde. / Er hatte Hunger. / Sie musste gehen. |

---

## Slabi glagoli (pravilni)

Koren + **-te** nastavci:

**machen** · raditi · `machte / machtest / machte / machten / machtet / machten`

**lernen** · učiti · `lernte / lerntest / lernte / lernten / lerntet / lernten`

**arbeiten** · raditi · `arbeitete / arbeitetest / arbeitete / arbeiteten / arbeitetet / arbeiteten`

> Koren na -d/-t dobija **-ete-** (kao u Präsensu): arbeiten → arbeit**ete**.

---

## Jaki glagoli (nepravilni)

Koren se menja — nastavci su: **— / -st / — / -en / -t / -en** (ich i er/sie/es nemaju nastavak).

**gehen** · ići · `ging / gingst / ging / gingen / gingt / gingen`

**kommen** · doći · `kam / kamst / kam / kamen / kamt / kamen`

**fahren** · voziti · `fuhr / fuhrst / fuhr / fuhren / fuhrt / fuhren`

**sprechen** · govoriti · `sprach / sprachst / sprach / sprachen / spracht / sprachen`

**schreiben** · pisati · `schrieb / schriebst / schrieb / schrieben / schriebt / schrieben`

**lesen** · čitati · `las / last / las / lasen / last / lasen`

**sehen** · videti · `sah / sahst / sah / sahen / saht / sahen`

**nehmen** · uzimati · `nahm / nahmst / nahm / nahmen / nahmt / nahmen`

**geben** · davati · `gab / gabst / gab / gaben / gabt / gaben`

**helfen** · pomagati · `half / halfst / half / halfen / halft / halfen`

**essen** · jesti · `aß / aßt / aß / aßen / aßt / aßen`

**trinken** · piti · `trank / trankst / trank / tranken / trankt / tranken`

**schlafen** · spavati · `schlief / schliefst / schlief / schliefen / schlieft / schliefen`

**bleiben** · ostati · `blieb / bliebst / blieb / blieben / bliebt / blieben`

**stehen** · stajati · `stand / standst / stand / standen / standt / standen`

**finden** · naći · `fand / fandst / fand / fanden / fandt / fanden`

**beginnen** · početi · `begann / begannst / begann / begannen / begannt / begannen`

**tragen** · nositi · `trug / trugst / trug / trugen / trugt / trugen`

**fallen** · padati · `fiel / fielst / fiel / fielen / fielt / fielen`

**laufen** · trčati · `lief / liefst / lief / liefen / lieft / liefen`

**werfen** · bacati · `warf / warfst / warf / warfen / warft / warfen`

**vergessen** · zaboraviti · `vergaß / vergaßt / vergaß / vergaßen / vergaßt / vergaßen`

**gewinnen** · pobediti · `gewann / gewannst / gewann / gewannen / gewannt / gewannen`

## sein — biti

Najvažniji nepravilni oblik. Koristi se i u govoru (ne Perfekt).

**sein** (Präteritum) · biti · `war / warst / war / waren / wart / waren`

```
Ich war müde.            → Bio/la sam umoran/na.
Wo warst du gestern?     → Gde si bio/la juče?
Es war kalt.             → Bilo je hladno.
Wir waren in Berlin.     → Bili smo u Berlinu.
```

---

## haben — imati

Takođe uvek Präteritum u govoru.

**haben** (Präteritum) · imati · `hatte / hattest / hatte / hatten / hattet / hatten`

```
Ich hatte Hunger.        → Bio/la sam gladan/gladna.
Er hatte keine Zeit.     → Nije imao vremena.
Wir hatten Glück.        → Imali smo sreće.
```

---

## werden — postati

**werden** (Präteritum) · postati · `wurde / wurdest / wurde / wurden / wurdet / wurden`

```
Er wurde Arzt.           → Postao je lekar.
Es wurde kalt.           → Postalo je hladno.
```

---

## Red reči u Präteritumu

Isti kao u Präsensu — glagol na 2. mestu:

```
Gestern war ich müde.           (inverzija)
Ich lernte drei Stunden.        (normalan red)
Kam er gestern?                 (pitanje)
Er kam nicht.                   (negacija)
```

### U sporednoj rečenici — glagol na kraju

```
Ich weiß, dass er müde war.
Als ich jung war, lebte ich in Berlin.
```
