# Mešoviti glagoli u Präteritumu

**Nivo:** A2–B1

Mešoviti glagoli uzimaju **slabe nastavke** (-te, -test, -te, -ten, -tet, -ten) ali koren se **menja** kao kod jakih.

---

## Konjugacija u Präteritumu

**denken** · misliti · `dachte / dachtest / dachte / dachten / dachtet / dachten`

**bringen** · doneti, nositi · `brachte / brachtest / brachte / brachten / brachtet / brachten`

**kennen** · poznavati · `kannte / kanntest / kannte / kannten / kanntet / kannten`

**nennen** · nazivati · `nannte / nanntest / nannte / nannten / nanntet / nannten`

**rennen** · trčati (brzo) · `rannte / ranntest / rannte / rannten / ranntet / rannten`

**brennen** · goreti · `brannte / branntest / brannte / brannten / branntet / brannten`

**wissen** · znati · `wusste / wusstest / wusste / wussten / wusstet / wussten`

**senden** · slati · `sandte / sandtest / sandte / sandten / sandtet / sandten`

**wenden** · okrenuti · `wandte / wandtest / wandte / wandten / wandtet / wandten`

---

## Promena korena — pregled

| Infinitiv | Koren (Präsens) | Koren (Präteritum) | Promena |
|-----------|----------------|-------------------|---------|
| denken | denk- | dach- | e+nk → ach |
| bringen | bring- | brach- | ing → ach |
| kennen | kenn- | kann- | e → a |
| nennen | nenn- | nann- | e → a |
| rennen | renn- | rann- | e → a |
| brennen | brenn- | brann- | e → a |
| wissen | wiss-/weiß- | wuss- | i → u |
| senden | send- | sand- | e → a |
| wenden | wend- | wand- | e → a |

---

## Primeri u rečenicama

```
Ich dachte, er kommt.          → Mislio/la sam da dolazi.
Er brachte Blumen mit.         → Doneo je cveće sa sobom.
Ich kannte ihn gut.            → Dobro sam ga poznavao/la.
Das Haus brannte.              → Kuća je gorela.
Ich wusste es nicht.           → Nisam to znao/la.
Sie wandte sich an mich.       → Obratila se meni.
```
