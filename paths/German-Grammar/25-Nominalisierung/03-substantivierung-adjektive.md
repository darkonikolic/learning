# Substantivierung von Adjektiven — Pridevi kao imenice

**Nivo:** B2

Pridevi i participi mogu se koristiti **kao imenice** — pišu se velikim slovom ali zadržavaju pridevske nastavke. Ova kategorija je veoma produktivna u nemačkom i neophodna za B2.

---

## Osnovno pravilo

Kada pridev postane imenica, on **i dalje prima pridevske nastavke** — zavisno od toga da li ima član (određeni, neodređeni) ili ga nema:

```
der Alte    → stari čovek    (sa određenim članom → slabi nastavak)
ein Alter   → jedan starac   (sa neodređenim članom → mešoviti nastavak)
Alte        → starci (gen.)  (bez člana → jaki nastavak)
```

---

## Deklinacija: sa određenim članom (slaba deklinacija)

| Padež | Muški | Ženski | Srednji | Množina |
|---|---|---|---|---|
| Nom. | der Alte | die Alte | das Gute | die Alten |
| Akk. | den Alten | die Alte | das Gute | die Alten |
| Dat. | dem Alten | der Alten | dem Guten | den Alten |
| Gen. | des Alten | der Alten | des Guten | der Alten |

## Deklinacija: sa neodređenim članom (mešovita)

| Padež | Muški | Ženski | Srednji |
|---|---|---|---|
| Nom. | ein Alter | eine Alte | ein Gutes |
| Akk. | einen Alten | eine Alte | ein Gutes |
| Dat. | einem Alten | einer Alten | einem Guten |
| Gen. | eines Alten | einer Alten | eines Guten |

---

## Lista čestih supstantivizovanih prideva

### Osobe (muški i ženski rod)

```
alt      → der/die Alte        (starac/starica)
jung     → der/die Junge       (mladić/devojka) — pažnja: Junge = dečak!
krank    → der/die Kranke      (bolesnik/bolesnica)
gesund   → der/die Gesunde     (zdrava osoba)
fremd    → der/die Fremde      (stranac/strankinja)
bekannt  → der/die Bekannte    (poznanik/poznanica)
verwandt → der/die Verwandte   (rođak/rođaka)
angestellt → der/die Angestellte (zaposleni/zaposlena)
vorsitzend → der/die Vorsitzende (predsednik/predsednica)
abhängig → der/die Abhängige   (zavisnik/zavisnica)
```

### Apstraktni pojmovi (srednji rod)

```
gut   → das Gute     (dobro)
böse  → das Böse     (zlo)
schön → das Schöne   (lepo)
neu   → das Neue     (novo)
alt   → das Alte     (staro)
wichtig → das Wichtige (važno)
beste → das Beste    (najbolje)
richtig → das Richtige (ispravno)
nötig → das Nötige   (neophodno)
```

```
Das Gute daran ist, dass...
→ Dobra stvar u tome je da...

Wir müssen das Beste daraus machen.
→ Moramo izvući najbolje iz toga.

Er hat das Richtige getan.
→ Uradio je pravu stvar.
```

## Participi kao imenice

Partizip I i Partizip II takođe mogu biti supstantivizovani:

### Partizip I → osoba koja vrši radnju

```
reisen   → reisend   → der/die Reisende      (putnik/putnica)
lehren   → lehrend   → der/die Lehrende      (nastavnik/nastavnica, form.)
vorsitzen → vorsitzend → der/die Vorsitzende  (predsednik/predsednica)
teilnehmen → teilnehmend → der/die Teilnehmende (učesnik/učesnica)
studieren → studierend → der/die Studierende  (student/studentkinja, form.)
arbeiten → arbeitend → der/die Arbeitende    (radnik/radnica)
```

### Partizip II → osoba koja je bila objekat radnje ili apstraktno

```
anstellen → angestellt → der/die Angestellte    (zaposleni/zaposlena)
verletzen → verletzt   → der/die Verletzte      (povređeni/povređena)
gefangen nehmen → gefangen → der/die Gefangene  (zatvorenik/zatvorеnica)
vermissen → vermisst  → der/die Vermisste       (nestali/nestala)
erfahren  → erfahren  → der/die Erfahrene       (iskusan/iskusna — adj.)
```

```
Der Verletzte wurde ins Krankenhaus gebracht.
→ Povređeni je odvezen u bolnicu.

Die Angestellten streiken.
→ Zaposleni štrajkuju.

Ein Reisender hat das gefunden.
→ Jedan putnik je to pronašao.
```

## Posebni slučajevi

### Superlativ kao imenica

```
das Beste    → das Beste aus etwas machen (izvući najbolje)
das Wichtigste → das Wichtigste zuerst (najvažnije prvo)
das Schwerste → das Schwerste liegt hinter uns (najteže je iza nas)
das Mindeste → das ist das Mindeste (to je minimum)
```

### Posle etwas, nichts, viel, alles, wenig

Posle ovih reči pridev se piše **velikim slovom** i dobija nastavak **-es** (jaka deklinacija, srednji rod):

```
etwas Gutes     → nešto dobro
nichts Neues    → ništa novo
viel Wichtiges  → mnogo važnih stvari
alles Schöne    → sve lepo
wenig Interessantes → malo zanimljivih stvari
```

```
Ich habe nichts Besonderes gemacht.
→ Nisam uradio/la ništa posebno.

Gibt es etwas Neues?
→ Ima li nečeg novog?

Er hat alles Mögliche versucht.
→ Pokušao je sve moguće.
```

## Česte greške

**Greška 1:** Pisanje malim slovom

```
✗ der alte kam spät.
✓ Der Alte kam spät.
→ Supstantivizovani pridev se UVEK piše velikim slovom.
```

**Greška 2:** Pogrešan nastavak

```
✗ Ein Alte sagte...
✓ Ein Alter sagte...  (muški rod, neodređeni član → mešovita deklinacija → -er)
```

**Greška 3:** Zaboravljanje roda

```
✗ der Bekannte / die Bekannte — koji je tačan?
→ Oba su tačna! Rod zavisi od pola osobe: der Bekannte (muška osoba), die Bekannte (ženska osoba).
```
