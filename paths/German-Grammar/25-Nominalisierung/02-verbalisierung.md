# Verbalisierung — Verbalizacija

**Nivo:** B2

Verbalizacija je obrnuti proces od nominalizacije: **imenica ili nominalizovana fraza → glagol ili glagolska fraza**. Ključno za razumevanje formalnih tekstova i za aktivno pisanje na B2 nivou — i u jednom i u drugom smeru.

---

## Šta je verbalizacija?

U formalnom nemačkom jeziku, mnoge radnje se izražavaju kroz **Funktionsverbgefüge** (funkcionalne glagolske veze) — kombinacija glagola + imenica umesto jednog glagola:

```
die Entscheidung treffen  =  entscheiden
eine Frage stellen        =  fragen
Kritik üben               =  kritisieren
```

Razumeti obe forme je obavezno za B2 ispit — u čitanju i pisanju.

## Detaljna objašnjenja ključnih fraza

### zur Verfügung stehen / stellen

```
Das Geld steht zur Verfügung.     → Das Geld ist verfügbar.
→ Novac je dostupan / na raspolaganju.

Wir stellen die Räume zur Verfügung.  → Wir bieten die Räume an.
→ Stavljamo prostorije na raspolaganje.
```

### Einfluss nehmen auf

```
Die Medien nehmen Einfluss auf die Meinung.
= Die Medien beeinflussen die Meinung.
→ Mediji utiču na mišljenje.
```

### Rücksicht nehmen auf

```
Man muss auf die Umwelt Rücksicht nehmen.
= Man muss die Umwelt berücksichtigen.
→ Treba voditi računa o životnoj sredini.
```

### zum Ausdruck bringen

```
Er brachte seine Unzufriedenheit zum Ausdruck.
= Er drückte seine Unzufriedenheit aus.
→ Izrazio je svoje nezadovoljstvo.
```

### in Anspruch nehmen

```
Diese Arbeit nimmt viel Zeit in Anspruch.
= Diese Arbeit beansprucht viel Zeit.
→ Ovaj posao oduzima mnogo vremena.
```

### in Kraft treten

```
Das Gesetz tritt am 1. Januar in Kraft.
= Das Gesetz wird am 1. Januar gültig.
→ Zakon stupa na snagu 1. januara.
```

## Primeri transformacija u oba smera

### Nominalna fraza → Glagolska rečenica

```
Die Entscheidung wurde getroffen, das Projekt zu verlängern.
→ Man entschied, das Projekt zu verlängern.
→ Odlučeno je da se projekat produži.

Die Frage nach den Kosten wurde gestellt.
→ Man fragte nach den Kosten.
→ Postavljeno je pitanje o troškovima.

Der Einfluss der Werbung auf Kinder ist nicht zu unterschätzen.
→ Werbung beeinflusst Kinder erheblich.
→ Reklame značajno utiču na decu.
```

### Glagolska rečenica → Nominalna fraza

```
Man hat das Problem gelöst.
→ Die Lösung des Problems wurde gefunden.
→ Pronađeno je rešenje problema.

Die Regierung hat neue Maßnahmen eingeführt.
→ Die Einführung neuer Maßnahmen durch die Regierung erfolgte.
→ Vlada je uvela nove mere. / Uvođenje novih mera od strane vlade je izvršeno.
```

## Glagoli u Funktionsverbgefüge — najčešći

| Glagol | Tipične veze |
|---|---|
| **nehmen** | Einfluss nehmen, Rücksicht nehmen, in Anspruch nehmen, in Betrieb nehmen |
| **stellen** | eine Frage stellen, zur Verfügung stellen, in Frage stellen |
| **treffen** | eine Entscheidung treffen, eine Wahl treffen, Maßnahmen treffen |
| **bringen** | zum Ausdruck bringen, in Gang bringen, zur Geltung bringen |
| **kommen** | in Frage kommen, in Kraft kommen, zum Einsatz kommen |
| **stehen** | zur Verfügung stehen, unter Druck stehen, in Verbindung stehen |
| **üben** | Kritik üben, Einfluss üben, Druck ausüben |
| **finden** | Anwendung finden, Berücksichtigung finden, Verwendung finden |

---

## Česte greške

**Greška:** Mešanje rekcije (predlog + padež):

```
✗ Einfluss nehmen über die Entscheidung
✓ Einfluss nehmen auf die Entscheidung (Akkusativ)

✗ Rücksicht nehmen für die anderen
✓ Rücksicht nehmen auf die anderen (Akkusativ)

✗ Bezug nehmen zu dem Bericht
✓ Bezug nehmen auf den Bericht (Akkusativ)
```
