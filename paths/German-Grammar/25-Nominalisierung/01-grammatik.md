# Nominalisierung — Nominalizacija

**Nivo:** B2

Nominalizacija je pretvaranje glagola i prideva u imenice. Ključna je za pisani B2 stil — akademske tekstove, poslovnu komunikaciju i novinski jezik. Nominalizovani stil čini tekst formalnijim, kompaktnijim i objektičnijim.

---

## Zašto nominalizacija?

```
Govorni stil:   Wir müssen das Problem schnell lösen.
Pisani stil:    Eine schnelle Lösung des Problems ist notwendig.

Govorni stil:   Man hat entschieden, dass...
Pisani stil:    Die Entscheidung, dass...
```

---

## Tvorba 1: Infinitiv → imenica (srednji rod)

Svaki nemački infinitiv može postati imenica **srednjeg roda** jednostavnim pisanjem velikim slovom:

```
lernen   → das Lernen    (učenje)
schreiben → das Schreiben (pisanje)
laufen   → das Laufen    (trčanje)
arbeiten → das Arbeiten  (rad)
fahren   → das Fahren    (vožnja)
essen    → das Essen     (jelo/hrana)
trinken  → das Trinken   (pijenje)
schwimmen → das Schwimmen (plivanje)
```

```
Das Lernen fällt ihm schwer.
→ Učenje mu ide teško.

Das Rauchen ist hier verboten.
→ Pušenje je ovde zabranjeno.
```

---

## Tvorba 2: -ung (ženski rod)

Nastavak **-ung** je najproduktivniji za prelazne glagole. Uvek ženski rod.

```
lösen      → die Lösung        (rešenje)
erklären   → die Erklärung     (objašnjenje)
entscheiden → die Entscheidung  (odluka)
beschreiben → die Beschreibung  (opis)
vorbereiten → die Vorbereitung  (priprema)
verbessern  → die Verbesserung  (poboljšanje)
entwickeln  → die Entwicklung   (razvoj)
bedeuten   → die Bedeutung     (značenje)
ordnen     → die Ordnung       (red/poredak)
regieren   → die Regierung     (vlada)
wohnen     → die Wohnung       (stan)
erfahren   → die Erfahrung     (iskustvo)
hoffnen    → die Hoffnung      (nada)
ändern     → die Änderung      (promena)
fordern    → die Forderung     (zahtev)
```

**Pažnja:** Ne može svaki glagol → -ung. Kod sumnje koristiti rečnik.

---

## Tvorba 3: -tion / -ation (ženski rod)

Glagoli stranog porekla koji se završavaju na **-ieren** često daju imenice na **-tion**:

```
informieren   → die Information    (informacija)
organisieren  → die Organisation   (organizacija)
kommunizieren → die Kommunikation  (komunikacija)
konstruieren  → die Konstruktion   (konstrukcija)
produzieren   → die Produktion     (proizvodnja)
reagieren     → die Reaktion       (reakcija)
funktionieren → die Funktion       (funkcija)
diskutieren   → die Diskussion     (diskusija)
demonstrieren → die Demonstration  (demonstracija)
```

**Naglasak:** uvek na poslednjoj/pretposlednjoj slogu (-tsi-ON).

---

## Tvorba 4: -nis (srednji ili ženski rod)

```
erkennen  → das Erkenntnis   (saznanje, spoznaja)
erleben   → das Erlebnis     (doživljaj)
versprechen → das Versprechen (obećanje) [inf.]
vergessen  → das Vergessen   (zaborav)
ergebnis   → das Ergebnis    (rezultat) [od ergeben]
kennen    → die Kenntnis     (znanje, poznavanje)
```

**Rod:** uglavnom srednji, ali die Kenntnis/Erkenntnis može biti i ženski (die Erkenntnis).

---

## Tvorba 5: -heit / -keit / -igkeit (ženski rod)

Od **prideva** → imenice koje izražavaju apstraktne osobine:

**-heit** (za jednosložne i prideve na -ig, -lich):

```
frei      → die Freiheit       (sloboda)
krank     → die Krankheit      (bolest)
gesund    → die Gesundheit     (zdravlje)
schön     → die Schönheit      (lepota)
wahr      → die Wahrheit       (istina)
dunkel    → die Dunkelheit     (tama)
```

**-keit** (za prideve na -sam, -bar, -lich, -ig):

```
pünktlich  → die Pünktlichkeit   (tačnost)
möglich    → die Möglichkeit     (mogućnost)
schwierig  → die Schwierigkeit   (teškoća)
einig      → die Einigkeit       (jedinstvo)
zuverlässig → die Zuverlässigkeit (pouzdanost)
wichtig    → die Wichtigkeit     (važnost)
```

**-igkeit** (za duge prideve na -ig):

```
neugierig   → die Neugierigkeit    (radoznalost)
unabhängig  → die Unabhängigkeit   (nezavisnost)
selbstständig → die Selbstständigkeit (samostalnost)
```

---

## Tvorba 6: -schaft (ženski rod)

Izražava kolektiv, zajednicu, odnos ili stanje:

```
arbeiten    → die Arbeiterschaft  (radnička klasa)
Freund      → die Freundschaft    (prijateljstvo)
Gesellschaft → — (već imenica)    (društvo)
Mannschaft  → die Mannschaft      (tim/ekipa)
Wissenschaft → —                  (nauka)
Eigenschaft → —                   (osobina)
```

---

## Primeri nominalizovanog stila u tekstu

```
Govorni:   Wir haben entschieden, das Projekt zu beenden.
Pisani:    Die Entscheidung, das Projekt zu beenden, wurde getroffen.

Govorni:   Es ist wichtig, dass man pünktlich ist.
Pisani:    Die Pünktlichkeit ist von großer Bedeutung.

Govorni:   Man hat das Problem erkannt und eine Lösung gefunden.
Pisani:    Die Erkenntnis des Problems führte zur Entwicklung einer Lösung.
```

---

## Pregled nastavaka

| Nastavak | Rod | Od | Primer |
|---|---|---|---|
| [Infinitiv] | srednji | glagola | das Lernen |
| -ung | ženski | prelaznih glagola | die Lösung |
| -tion/-ation | ženski | -ieren glagola | die Information |
| -nis | srednji/ženski | glagola | das Erlebnis |
| -heit | ženski | prideva | die Freiheit |
| -keit | ženski | prideva na -lich/-ig | die Möglichkeit |
| -schaft | ženski | imenica/glagola | die Freundschaft |
