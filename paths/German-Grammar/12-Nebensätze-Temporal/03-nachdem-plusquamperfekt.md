# nachdem + Plusquamperfekt

**Nivo:** B1

**nachdem** znači "pošto, nakon što" — radnja u sporednoj rečenici desila se **pre** radnje u glavnoj rečenici. Zbog tog vremenskog pomaka, u sporednoj rečenici obično stoji **Plusquamperfekt**.

---

## Pravilo

```
Nachdem + [Plusquamperfekt] → [Präteritum / Perfekt]
         ↑ starija radnja      ↑ novija radnja
```

---

## Primeri s vremenskom linijom

```
→ →   pojeo        →   šetnja
     (starije)        (novije)

Nachdem er gegessen hatte, machte er einen Spaziergang.
Pošto je pojeo, išao je u šetnju.
```

```
→ →   završila posao    →    otišla kući
       (starije)              (novije)

Nachdem sie die Arbeit beendet hatte, fuhr sie nach Hause.
Pošto je završila posao, otišla je kući.
```

```
Nachdem wir angekommen waren, suchten wir ein Hotel.
Pošto smo stigli, tražili smo hotel.

Nachdem er das Buch gelesen hatte, gab er es zurück.
Pošto je pročitao knjigu, vratio ju je.

Nachdem sie aufgestanden war, duschte sie sofort.
Pošto je ustala, odmah se otušovala.
```

---

## Kad je glavna rečenica u Präsensu/Futuru

Kad govorimo o sadašnjosti ili budućnosti, sporedna rečenica (starija radnja) stoji u **Perfektu**:

```
Nachdem ich gegessen habe, mache ich einen Spaziergang.
Pošto sam pojeo/la, idem u šetnju.

Nachdem er die Prüfung bestanden hat, fährt er in Urlaub.
Pošto je položio ispit, putuje na odmor.
```

---

## Tabela vremenskih kombinacija

| Glavna rečenica | Sporedna (nachdem) |
|-----------------|-------------------|
| Präteritum / Perfekt | **Plusquamperfekt** |
| Präsens / Futur | **Perfekt** |

---

## Poređenje: als vs. nachdem

| | als | nachdem |
|--|-----|---------|
| **Značenje** | kad (u isto vreme ili tačan momenat) | pošto (pre toga) |
| **Vreme radnje** | jednovremeno / tačan momenat | starija radnja (pre glavne) |
| **Vreme u sporednoj** | Präteritum | Plusquamperfekt (ili Perfekt) |
| **Primer** | Als er ankam, aßen wir. | Nachdem er gegessen hatte, ging er. |

```
Als er ins Zimmer kam, setzte sie sich.
Kad je ušao u sobu, ona je sela. (isti momenat)

Nachdem er ins Zimmer gekommen war, setzte sie sich.
Pošto je ušao u sobu, ona je sela. (prvo ušao, pa sela)
```

---

## Plusquamperfekt — podsetnik

**haben/sein** u Präterituму + Partizip II:

```
hatte gegessen   (jeo)
war  gegangen    (otišao)
hatte geschrieben (napisao)
war  aufgestanden (ustao)
```

Glagoli kretanja i promene stanja → **sein**
Ostali glagoli → **haben**

---

## Red reči

Kad **nachdem-rečenica** stoji ispred, glavna počinje glagolom:

```
Nachdem er gegessen hatte, → machte er einen Spaziergang.
                              ↑ glagol odmah posle zareza
```
