# Indirektni govor sa dass

**Nivo:** B2


Indirektni govor prenosi tuđe reči bez navodnika. U nemačkom se koristi **dass** ili Konjunktiv I.

---

## Osnovna struktura

```
Direktno:    Er sagt: „Ich bin müde."
Indirektno:  Er sagt, dass er müde ist.
                           ↑ zamenica se menja   ↑ glagol na kraju
```

---

## Promena zamenica

Zamenica se menja prema tome ko govori i o kome:

| Direktni govor | Indirektni govor |
|---|---|
| Er sagt: „**Ich** lerne Deutsch." | Er sagt, dass **er** Deutsch lernt. |
| Sie sagt: „**Ich** bin müde." | Sie sagt, dass **sie** müde ist. |
| Er sagt: „**Du** machst Fehler." | Er sagt, dass **ich** Fehler mache. |
| Sie sagt: „**Wir** fahren morgen." | Sie sagt, dass **sie** morgen fahren. |
| Er sagt: „**Ihr** habt recht." | Er sagt, dass **wir** recht haben. |

> Uvek razmisliti: ko govori? o kome govori? → odaberi odgovarajuću zamenicu.

---

## Promena vremena

### Präsens → Präteritum (u razgovornom jeziku)

U svakodnevnom govoru Präsens sporedne rečenice prelazi u Präteritum:

| Direktno (Präsens) | Indirektno (Präteritum) |
|---|---|
| „Ich **bin** krank." | Er sagte, dass er krank **war**. |
| „Sie **arbeitet** viel." | Er sagte, dass sie viel **arbeitete**. |
| „Wir **haben** keine Zeit." | Er sagte, dass sie keine Zeit **hatten**. |
| „Er **kann** kommen." | Er sagte, dass er kommen **konnte**. |

### Präsens → Konjunktiv I (u pisanom / formalnom jeziku)

U novinarskom i formalnom pisanju koristi se **Konjunktiv I**:

| Direktno | Konjunktiv I oblik | Indirektno |
|---|---|---|
| „Ich **bin**..." | er **sei** | Er sagt, er **sei** krank. |
| „Ich **habe**..." | er **habe** | Er sagt, er **habe** keine Zeit. |
| „Ich **komme**..." | er **komme** | Er sagt, er **komme** morgen. |
| „Ich **kann**..." | er **könne** | Er sagt, er **könne** helfen. |

> Kad je Konjunktiv I jednak Präsensu (z.b. *sie lernen* = Konj. I), koristi se **Konjunktiv II** ili **würde + Infinitiv** da se naglasi indirektnost.

---

## Primeri: Direktan → Indirektni govor

### Razgovorni jezik (Präteritum)

| Direktno | Indirektno |
|---|---|
| Er sagt: „Ich lerne Deutsch." | Er sagt, dass er Deutsch **lernte**. |
| Sie sagt: „Ich bin glücklich." | Sie sagt, dass sie glücklich **war**. |
| Er sagt: „Wir fahren nach Berlin." | Er sagt, dass sie nach Berlin **fuhren**. |
| Sie sagt: „Ich kann nicht kommen." | Sie sagt, dass sie nicht kommen **konnte**. |
| Er sagt: „Du hast recht." | Er sagt, dass ich recht **hatte**. |

### Formalni jezik (Konjunktiv I)

| Direktno | Indirektno |
|---|---|
| Der Minister sagt: „Ich unterstütze das Projekt." | Der Minister sagt, dass er das Projekt **unterstütze**. |
| Die Expertin erklärt: „Die Lage ist ernst." | Die Expertin erklärt, dass die Lage ernst **sei**. |
| Er berichtet: „Das Land hat Probleme." | Er berichtet, dass das Land Probleme **habe**. |

---

## Bez dass — bez veznika

Indirektni govor može i bez *dass* — tada nema promene reda reči u sporednoj:

```
Er sagt, dass er müde ist.   (sa dass — glagol na kraju)
Er sagt, er ist müde.        (bez dass — normalan red reči)
```

Oba oblika su pravilna. Bez *dass* je češće u govoru.

---

## Promena vremenskih odredbi

| Direktno | Indirektno |
|---|---|
| heute (danas) | an dem Tag (tog dana) |
| morgen (sutra) | am nächsten Tag (sledećeg dana) |
| gestern (juče) | am Tag zuvor / am Vortag |
| hier (ovde) | dort (tamo) |
| jetzt (sada) | da / dann |

```
Er sagt: „Ich komme heute."
→ Er sagte, dass er an dem Tag kommt / käme.
```
