# während — Kontrast vs Vreme

**Nivo:** B2

Während je jedan od retkih nemačkih veznika koji ima **dve potpuno različite funkcije** — temporalnu (vreme) i adversativnu (kontrast). Rečenična struktura je ista u oba slučaja, ali značenje se razlikuje na osnovu konteksta.

---

## während: dva značenja

| Upotreba | Srpski | Pitanje |
|---|---|---|
| Temporalno | dok, za vreme | Kada se to dešava? Istovremeno? |
| Adversativno | dok (nasuprot), za razliku od | Da li su ovo u kontrastu? |

---

## während — temporalno (istovremene radnje)

Radnje u obe rečenice dešavaju se **u isto vreme**:

```
Während ich schlafe, arbeitet er.
→ Dok ja spavam, on radi.  (istovremeno!)

Während sie kochte, las er die Zeitung.
→ Dok je ona kuvala, on je čitao novine.  (istovremeno!)

Während des Sommers fahren viele in den Urlaub.
→ Za vreme leta, mnogi idu na odmor.
```

**Test:** Da li se obe radnje dešavaju u isto vreme? → temporalno.

---

## während — adversativno (kontrast)

Radnje u obe rečenice su u **kontrastu** — ne moraju biti istovremene:

```
Während er fleißig ist, ist sie faul.
→ Dok je on marljiv, ona je lejna.  (kontrast!)

Während Deutschland viel exportiert, importiert Griechenland mehr.
→ Dok Nemačka mnogo izvozi, Grčka više uvozi.  (kontrast!)

Während manche Studenten früh aufstehen, schlafen andere bis Mittag.
→ Dok neki studenti rano ustaju, drugi spavaju do podne.  (kontrast!)
```

**Test:** Da li rečenica opisuje suprotnost, razliku? → adversativno.

---

## Kako razlikovati iz konteksta?

**Ključno pitanje:** Da li su subjekti/situacije u kontrastu ili se radnje odvijaju paralelno?

```
Während er schläft, arbeitet sie.
→ AMBIVALENTNO! Može biti i temporalno i adversativno.
→ Kontekst rešava: da li je poruka "u isto vreme" ili "on spava, a ona radi"?

Während er Arzt ist, ist sie Lehrerin.
→ Adversativno (jasno) — zanimanja su različita, ne istovremena!

Während sie singt, tanzt er.
→ Temporalno (jasno) — obe radnje se dešavaju u isto vreme.
```

---

## Transformacije: während ↔ dagegen ↔ aber

Iste poruke mogu se izraziti na različite načine:

### Primer 1 — kontrast marljiv/len

```
während (sporedna rečenica):
Während er fleißig ist, ist sie faul.

dagegen (prilog, inverzija):
Er ist fleißig. Sie dagegen ist faul.
Er ist fleißig, sie dagegen ist faul.

aber (koordinirajući veznik):
Er ist fleißig, aber sie ist faul.
```

### Primer 2 — kontrast cene/plate

```
während:
Während die Preise steigen, stagnieren die Löhne.

dagegen:
Die Preise steigen. Dagegen stagnieren die Löhne.

wohingegen:
Die Preise steigen, wohingegen die Löhne stagnieren.

allerdings:
Die Preise steigen. Die Löhne allerdings stagnieren.
```

### Primer 3 — kontrast optimizam/pesimizam

```
während:
Während er optimistisch ist, ist sie pessimistisch.

hingegen:
Er ist optimistisch. Sie hingegen ist pessimistisch.

aber:
Er ist optimistisch, aber sie ist pessimistisch.
```

## Primeri iz pisanog i govornog jezika

### Pisani (novinarski/akademski):

```
Die Exportquote ist gestiegen, wohingegen die Importe zurückgegangen sind.
→ Stopa izvoza je porasla, dok su uvozi opali.

Während die östlichen Bundesländer wachsen, stagniert der Westen.
→ Dok istočne savezne pokrajine rastu, zapad stagnira.
```

### Pisani (standardni):

```
Die neue Methode ist effizienter, während die alte mehr Ressourcen verbraucht.
→ Nova metoda je efikasnija, dok stara troši više resursa.
```

### Govorni:

```
Er hat viel gelernt, aber sie kaum.
→ On je mnogo učio, ali ona skoro nimalo.

Ich mag Kaffee, sie dagegen trinkt nur Tee.
→ Ja volim kafu, ona nasuprot tome pije samo čaj.
```

## Česte greške

**Greška 1:** Inverzija posle aber

```
✗ Er ist fleißig, aber ist sie faul.
✓ Er ist fleißig, aber sie ist faul.
→ Aber je koordinirajući veznik — bez inverzije!
```

**Greška 2:** Glagol na 2. mestu posle während

```
✗ Während er ist fleißig, ist sie faul.
✓ Während er fleißig ist, ist sie faul.
→ Während uvodi sporednu rečenicu → glagol na kraju!
```

**Greška 3:** Korišćenje sondern umesto aber za kontrast

```
✗ Er ist fleißig, sondern sie ist faul.
✓ Er ist fleißig, aber sie ist faul.
→ Sondern SAMO posle negacije (nicht, kein).
```

**Greška 4:** Bez zareza ispred während/wohingegen

```
✗ Während er arbeitet sie schläft.
✓ Während er arbeitet, schläft sie.
→ Uvek zarez ispred sporedne rečenice!
```
