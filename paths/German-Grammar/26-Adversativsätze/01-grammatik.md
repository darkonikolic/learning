# Adversativsätze — Suprotne rečenice

**Nivo:** B1–B2

Suprotne rečenice (Adversativsätze) izražavaju **kontrast ili suprotnost** između dve tvrdnje. Za razliku od koncesivnih rečenica (koje izražavaju ustupak — "iako"), adversativne rečenice jednostavno stavljaju dve situacije u kontrast — "ovde X, tamo Y".

Veznici se dele prema gramatičkom tipu i poziciji u rečenici.

---

## Tip 1: Sporedna rečenica — glagol na kraju

### während (kao kontrast — ne vreme!)

Während u adversativnom značenju ("dok" = "nasuprot tome") uvodi sporednu rečenicu sa glagolom na kraju.

```
Während er fleißig ist, ist sie faul.
→ Dok je on marljiv, ona je lejna.

Er arbeitet viel, während sie wenig tut.
→ On mnogo radi, dok ona malo čini.

Während Deutschland exportiert, importiert Griechenland mehr.
→ Dok Nemačka izvozi, Grčka više uvozi.
```

**Pažnja:** während može biti i temporalni veznik ("dok/za vreme"). Razlikovanje → [02-waehrend-als-kontrast.md](02-waehrend-als-kontrast.md)

---

### wohingegen (formalno, pisani jezik)

Wohingegen uvodi sporednu rečenicu — glagol na kraju. Nešto formalnije od während.

```
Er arbeitet viel, wohingegen sie wenig tut.
→ On mnogo radi, dok ona malo čini.

Die Preise steigen, wohingegen die Löhne stagnieren.
→ Cene rastu, dok plate stagniraju.
```

---

## Tip 2: Prilog u glavnoj rečenici — inverzija

Ovi veznici su **Konjunktionaladverbien** — stoje u glavnoj rečenici i uzrokuju **inverziju** (glagol odmah posle priloga, subjekt iza):

```
Prilog kommt. Dagegen ist es kalt.
        ↑ na prvom mestu → inverzija
```

### dagegen

Najčešći adversativni prilog. Može stajati na početku rečenice (inverzija) ili iza subjekta:

```
Er ist fleißig. Dagegen ist sie faul.
→ On je marljiv. Nasuprot tome, ona je lejna.

Er ist fleißig, sie dagegen ist faul.
→ On je marljiv, ona nasuprot tome lejna.
```

---

### hingegen (nešto formalnije od dagegen)

```
Er ist optimistisch, sie hingegen ist pessimistisch.
→ On je optimista, ona nasuprot tome pesimista.

Die Theorie klingt gut. Die Praxis hingegen sieht anders aus.
→ Teorija zvuči dobro. Praksa nasuprot tome izgleda drugačije.
```

---

### demgegenüber (formalno, akademski/novinarski)

```
Die Kosten sind gestiegen. Demgegenüber sind die Gewinne gesunken.
→ Troškovi su porasli. Nasuprot tome, profiti su pali.

Die alte Methode war ineffizient. Demgegenüber bietet das neue Verfahren viele Vorteile.
→ Stara metoda je bila neefikasna. Nasuprot njoj, novi postupak nudi mnogo prednosti.
```

---

### jedoch (međutim, ipak)

Jednak po značenju als aber, ali uzrokuje inverziju:

```
Er versuchte es, jedoch scheiterte er.
→ Pokušao je, međutim doživeo je neuspeh.

Das Konzept war gut. Jedoch fehlte das Geld.
→ Koncept je bio dobar. Međutim, nedostajao je novac.
```

---

### allerdings (doduše, međutim, samo što)

Izražava ograničenje ili kontrast — blisko zwar...aber:

```
Er ist intelligent, allerdings ist er auch faul.
→ On je inteligentan, doduše/ali je i len.

Das Restaurant ist gut. Allerdings ist es sehr teuer.
→ Restoran je dobar. Međutim, veoma je skup.
```

---

## Tip 3: Koordinirajući veznik — normalan red reči

Ovi veznici stoje **između** dve nezavisne rečenice i ne uzrokuju inverziju u drugoj rečenici:

### aber (ali)

Najčešći i najneutralniji adversativni veznik:

```
Er ist fleißig, aber sie ist faul.
→ On je marljiv, ali ona je lejna.

Ich verstehe das, aber ich bin nicht einverstanden.
→ Razumem to, ali se ne slažem.
```

---

### doch (ali, ipak — naglašen kontrast)

Doch naglašava iznenađenje ili jak kontrast:

```
Ich wollte kommen, doch es war unmöglich.
→ Hteo/la sam da dođem, ali je bilo nemoguće.

Er sieht jung aus, doch er ist schon 50.
→ Izgleda mlado, ali već ima 50 godina.
```

---

### sondern (nego — SAMO posle negacije)

Sondern ispravlja prethodnu negaciju — ne može se koristiti bez nicht/kein:

```
Nicht er, sondern sie hat das gemacht.
→ Ne on, nego ona je to uradila.

Das ist kein Fehler, sondern eine Absicht.
→ To nije greška, nego namera.

Er ist nicht müde, sondern krank.
→ On nije umoran, nego bolestan.
```

**Razlika aber vs sondern:**

```
Er ist intelligent, aber faul.       (aber — bez negacije, dodat kontrast)
Er ist nicht intelligent, sondern faul.  (sondern — posle negacije, ispravlja)
```
