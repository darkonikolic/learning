# Glagoli s prepozicionalnim objektom (Präpositionalobjekt)

**Nivo:** B1

Mnogi nemački glagoli zahtevaju **fiksnu prepoziciju** — ne možeš je birati ili menjati. Prepozicija i glagol čine celinu.

```
warten auf + Akkusativ
Ich warte auf den Bus.      Čekam autobus.
          ↑ fiksna prep ↑ Akk
```

---

## Pitanja za prepozicionalni objekat

Za **stvari i pojmove** — pitamo s **wo(r)- + prepozicija**:

```
Worauf wartest du?          Na šta čekaš?
Wofür interessierst du dich?  Za šta se interesuješ?
Womit fährst du?            Čime putuješ?
Worüber sprecht ihr?        O čemu govorite?
```

> Ako prepozicija počinje **samoglasnikom** → **wor-**: worauf, worüber, woran, woraus
> Ako počinje **suglasnikom** → **wo-**: wofür, womit, wovon, wozu

Za **osobe** — pitamo s **prepozicija + wen/wem**:

```
Auf wen wartest du?         Na koga čekaš?
Mit wem redest du?          S kim razgovaraš?
Über wen sprecht ihr?       O kome govorite?
```

---

## Odgovori — da(r)- + prepozicija za stvari

```
Worauf wartest du?
→ Ich warte darauf. / Ich warte auf den Bus.

Wofür interessierst du dich?
→ Ich interessiere mich dafür. / Ich interessiere mich für Musik.
```

> Detalji o da(r)- i wo(r)- → [../17-Pronominaladverbien/](../17-Pronominaladverbien/)

## Kako učiti

Uvek uči glagol **zajedno s prepozicijom i padežom**:

```
Nicht: sich interessieren
Besser: sich interessieren FÜR + Akkusativ
```

---

## Važna napomena o padežu

Isti glagol s različitom prepozicijom može imati različito značenje i padež:

```
denken an + Akk    → Ich denke an dich.          Mislim na tebe.
nachdenken über + Akk → Ich denke über das Problem nach.  Razmišljam o problemu.
```
