# Relativne rečenice s prepozicijama

**Nivo:** B2

Kad glagol u sporednoj rečenici zahteva prepoziciju, ta prepozicija dolazi **ispred relativne zamenice**.

```
Das ist das Thema, über das wir gesprochen haben.
To je tema o kojoj smo razgovarali.
(über + Akkusativ: über das)
```

---

## Prepozicija + relativna zamenica

Prepozicija stoji **direktno ispred** relativne zamenice. Padež određuje prepozicija.

**mit + Dativ:**
```
Der Kollege, mit dem ich arbeite, ist sehr nett.
Kolega s kojim radim je veoma ljubazan.
(m → Dativ → dem → mit dem)

Die Frau, mit der ich gesprochen habe, ist Ärztin.
Žena s kojom sam razgovarao/la je lekar.
(f → Dativ → der → mit der)
```

**für + Akkusativ:**
```
Das Projekt, für das ich arbeite, ist interessant.
Projekat za koji radim je zanimljiv.
(n → Akkusativ → das → für das)

Die Organisation, für die er sich einsetzt, hilft Kindern.
Organizacija za koju se on zalaže pomaže deci.
(f → Akkusativ → die → für die)
```

**über + Akkusativ:**
```
Das Buch, über das sie schreibt, ist ein Bestseller.
Knjiga o kojoj ona piše je bestseler.

Der Mann, über den alle reden, ist berühmt.
Muškarac o kome svi govore je poznat.
```

**in + Dativ:**
```
Die Stadt, in der ich aufgewachsen bin, heißt Novi Sad.
Grad u kome sam odrastao/la zove se Novi Sad.

Das Haus, in dem wir wohnen, ist alt.
Kuća u kojoj živimo je stara.
```

**von + Dativ:**
```
Der Autor, von dem ich das Buch habe, ist bekannt.
Autor od koga imam tu knjigu je poznat.
```

**an + Dativ:**
```
Das Projekt, an dem wir arbeiten, dauert noch lange.
Projekat na kome radimo još dugo traje.
```

## Česte kombinacije

| Predlog + padež | m | f | n | pl |
|-----------------|---|---|---|----|
| mit + Dat | mit dem | mit der | mit dem | mit denen |
| für + Akk | für den | für die | für das | für die |
| über + Akk | über den | über die | über das | über die |
| in + Dat | in dem | in der | in dem | in denen |
| von + Dat | von dem | von der | von dem | von denen |
| an + Dat | an dem | an der | an dem | an denen |
| bei + Dat | bei dem | bei der | bei dem | bei denen |
| zu + Dat | zu dem | zu der | zu dem | zu denen |

## Wo-Relativsatz — za mesta i apstraktne pojmove

Umesto prepozicija + relativna zamenica, za **mesta** se može koristiti **wo** (gde):

```
Das ist die Stadt, wo ich geboren wurde.
= Das ist die Stadt, in der ich geboren wurde.
To je grad gde sam rođen/a.

Das Land, wo er lebt, ist sehr schön.
= Das Land, in dem er lebt, ist sehr schön.
Zemlja gde on živi je veoma lepa.
```

> **wo** je neformalnije; **in dem / in der** je standardno.

Za apstraktne pojmove bez konkretnog mesta — **wo** nije moguće, koristi se prepozicija + zamenica:

```
Das ist der Grund, warum ich gegangen bin.  (warum / weshalb za razloge)
Das ist die Situation, in der wir uns befinden.
```

---

## Česta greška — pronominaladverb umesto relativne zamenice

Za **stvari** (ne osobe) u neformalnom govoru ponekad se čuje **wo(r)- + prepozicija**, ali u standardnom pisanom jeziku B2+ koristi se prepozicija + zamenica:

**Neformalno/govorno:** Das Thema, worüber wir reden...
**Standardno/pisano:** Das Thema, über das wir reden...

Za **osobe uvek** prepozicija + relativna zamenica (nikad wor-):

**Ispravno:** Der Mann, mit dem ich gesprochen habe...
**Pogrešno:** *Der Mann, womit ich gesprochen habe...*
