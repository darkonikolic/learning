# Partizip kao atribut — Transformacije

**Nivo:** B2

Sistematična vežba transformacije između relativnih rečenica i participijalnih atributa u oba smera.

---

## Relativna rečenica → Partizip I atribut

Koristiti kada relativna rečenica ima **Präsens aktiv** i isti subjekat.

**Korak 1:** Uzeti glagol iz relativne rečenice
**Korak 2:** Dodati -d (Partizip I forma)
**Korak 3:** Dodati pridevski nastavak prema rodu/padežu
**Korak 4:** Postaviti ispred imenice (brisati relativnu rečenicu)

```
1. der Hund, der bellt
   → bellen → bellend → der bellende Hund

2. die Sonne, die scheint
   → scheinen → scheinend → die scheinende Sonne

3. das Kind, das weint
   → weinen → weinend → das weinende Kind

4. die Studenten, die lernen
   → lernen → lernend → die lernenden Studenten

5. der Mann, der schläft
   → schlafen → schlafend → der schlafende Mann

6. die Wirtschaft, die wächst
   → wachsen → wachsend → die wachsende Wirtschaft

7. die Preise, die steigen
   → steigen → steigend → die steigenden Preise

8. der Zug, der ankommt
   → ankommen → ankommend → der ankommende Zug
```

---

## Relativna rečenica → Partizip II atribut

Koristiti kada relativna rečenica ima **Passiv** ili **Perfekt passiv**.

```
9. das Haus, das gebaut wurde
   → bauen → gebaut → das gebaute Haus

10. der Brief, der geschrieben wurde
    → schreiben → geschrieben → der geschriebene Brief

11. die Tür, die geöffnet wurde
    → öffnen → geöffnet → die geöffnete Tür

12. die Waren, die beschädigt wurden
    → beschädigen → beschädigt → die beschädigten Waren

13. das Auto, das repariert wurde
    → reparieren → repariert → das reparierte Auto

14. der Vertrag, der unterzeichnet wurde
    → unterzeichnen → unterzeichnet → der unterzeichnete Vertrag

15. die Wohnung, die renoviert wurde
    → renovieren → renoviert → die renovierte Wohnung
```

## Participijalni atribut → Relativna rečenica

Obrnuta transformacija — čitanje složenog atributa.

```
16. das laufende Kind
    → das Kind, das läuft

17. die weinende Frau
    → die Frau, die weint

18. der schlafende Hund
    → der Hund, der schläft

19. das renovierte Haus
    → das Haus, das renoviert wurde

20. der unterzeichnete Vertrag
    → der Vertrag, der unterzeichnet wurde

21. die steigende Temperatur
    → die Temperatur, die steigt

22. die beschädigten Waren
    → die Waren, die beschädigt wurden

23. das gebaute Gebäude
    → das Gebäude, das gebaut wurde
```

## Prošireni participijalni atribut — transformacije

Ove transformacije su najtipičnije za akademski/novinarski stil.

```
24. das Haus, das von der Firma gebaut wurde
    → das von der Firma gebaute Haus

25. der Zug, der gestern angekommen ist
    → der gestern angekommene Zug

26. die Frage, die seit Jahren diskutiert wird
    → die seit Jahren diskutierte Frage

27. ein Medikament, das von Wissenschaftlern entwickelt wurde
    → ein von Wissenschaftlern entwickeltes Medikament

28. der Bericht, der vom Minister vorgestellt wurde
    → der vom Minister vorgestellte Bericht

29. die Maßnahmen, die von der Regierung beschlossen wurden
    → die von der Regierung beschlossenen Maßnahmen

30. ein Konzept, das in den letzten Jahren entwickelt wurde
    → ein in den letzten Jahren entwickeltes Konzept
```

## Greške koje treba izbegavati

### Greška 1: Pogrešan nastavak na participu

```
✗ der bellende-e Hund
✓ der bellende Hund
→ Partizip prima jedan pridevski nastavak, ne dva.
```

### Greška 2: Partizip I za završenu/pasivnu radnju

```
✗ das bauende Haus (za "haus das gebaut wurde")
✓ das gebaute Haus
→ Partizip I = aktiv + istovremeno. Passiv/završeno = Partizip II.
```

### Greška 3: Promena vokala u Partizipu I

```
✗ das fahrende Auto → farend (pogrešno)
✓ das fahrende Auto → fahrend (osnova infinitiva + d)
→ Infinitiv uvek ostaje nepromenjen u Partizipu I.
```

### Greška 4: Ge- u participima s neodvojivim prefiksima

```
✗ das begeöffnete Fenster
✓ das geöffnete Fenster  (öffnen → geöffnet) ✓
✗ das gebedeakte Dokument
✓ das bedeckte Dokument  (bedecken → bedeckt, bez ge- jer be- je neodvojivo)
```

## Kada participijalni atribut NE može da se koristi

Participijalni atribut **nije moguć** u sledećim slučajevima:

**1. Relativna rečenica ima sopstveni subjekat (različit od imenice):**

```
das Haus, das mein Vater gebaut hat
→ ✗ das meinen Vater gebaute Haus — ne funkcioniše
→ ✓ das von meinem Vater gebaute Haus — OK sa von
→ ✓ das Haus, das mein Vater gebaut hat — ostati pri relativnoj rečenici
```

**2. Modalni glagol u relativnoj rečenici:**

```
das Buch, das man lesen muss
→ ✗ das zu lesende Buch? (rijetko, samo u veoma formalnom jeziku)
→ ✓ bolje: das Buch, das man lesen muss
```

**3. Relativna rečenica s predlogom (zamenica = nije subjekat):**

```
der Mann, auf den wir warten
→ ✗ ne može se pretvoriti u participijalni atribut
→ ✓ ostaje kao relativna rečenica
```

**4. Previše složena proširenja (teška čitljivosti):**

```
der von der internationalen Gemeinschaft seit Jahren intensiv diskutierte und
noch immer nicht gelöste Konflikt
→ Teorijski ispravno, ali nečitljivo — koristiti relativnu rečenicu.
```
