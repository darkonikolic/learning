# Partizip kao atribut

**Nivo:** B2

Participi kao atributi stoje **ispred imenice** umesto relativne rečenice. Tipični su za **pisani jezik** — novine, akademske tekstove, naučnu literaturu — jer čine stil kompaktnijim i ekonomičnijim. U govoru se retko koriste.

---

## Partizip I kao atribut — aktiv, istovremeno

**Tvorba Partizipa I:** Infinitiv + **-d** (+ pridevski nastavak)

```
laufen  → laufend-   → das laufende Kind
lächeln → lächelnd-  → die lächelnde Frau
schlafen → schlafend- → der schlafende Mann
arbeiten → arbeitend- → die arbeitende Bevölkerung
steigen  → steigend-  → die steigende Temperatur
```

**Značenje:** Partizip I označava radnju koja se odvija **istovremeno** sa radnjom glavnog glagola i **aktiv** (imenica sama vrši radnju).

```
das laufende Kind = das Kind, das läuft
→ dete koje trči

die lächelnde Frau = die Frau, die lächelt
→ žena koja se smeši

die wachsende Wirtschaft = die Wirtschaft, die wächst
→ privreda koja raste
```

---

## Partizip II kao atribut — passiv/aktiv, završeno

**Tvorba Partizipa II:** isti oblici kao u Perfektu i Passivu (ge- + koren + -t/en)

```
bauen   → gebaut    → das gebaute Haus
schreiben → geschrieben → der geschriebene Brief
öffnen  → geöffnet  → das geöffnete Fenster
renovieren → renoviert → die renovierte Wohnung
```

**Značenje:** Partizip II označava:
- radnju koja je **završena** pre radnje glavnog glagola
- kod prelaznih glagola: **passiv** (neko je uradio nešto imenici)

```
das gebaute Haus = das Haus, das gebaut wurde
→ kuća koja je sagrađena

der geschriebene Brief = der Brief, der geschrieben wurde
→ pismo koje je napisano

die beschädigten Waren = die Waren, die beschädigt wurden
→ oštećena roba
```

---

## Deklinacija — kao pridev

Oba participa se dekliniraju **tačno kao pridevi** — slaba, jaka ili mešovita deklinacija zavisno od člana:

**Sa određenim članom (slaba deklinacija):**

```
der laufende Mann      (nominativ, muški)
die laufende Frau      (nominativ, ženski)
das laufende Kind      (nominativ, srednji)
den laufenden Mann     (akuzativ, muški)
dem laufenden Kind     (dativ, srednji)
```

**Sa neodređenim članom (mešovita deklinacija):**

```
ein laufender Mann     (nominativ, muški)
eine laufende Frau     (nominativ, ženski)
ein laufendes Kind     (nominativ, srednji)
```

**Bez člana (jaka deklinacija):**

```
laufender Mann         (nominativ, muški)
laufende Frau          (nominativ, ženski)
```

## Prošireni atribut (Erweitertes Partizipialattribut)

Participijalni atribut može biti **proširen** dodacima — celom frazom koja stoji između člana i imenice. Ovo je karakteristično za akademski i novinarski stil:

```
das von der Firma gebaute Haus
= das Haus, das von der Firma gebaut wurde
→ kuća sagrađena od strane kompanije

der gestern angekommene Zug
= der Zug, der gestern angekommen ist
→ voz koji je stigao juče

die seit Jahren diskutierte Frage
= die Frage, die seit Jahren diskutiert wird
→ pitanje koje se godinama diskutuje

ein von Wissenschaftlern entwickeltes Medikament
= ein Medikament, das von Wissenschaftlern entwickelt wurde
→ lek razvijen od strane naučnika
```

**Red reči u proširenom atributu:** [član] + [dodaci] + [participijalni atribut] + [imenica]

## Transformacija: relativna rečenica → participijalni atribut

### Partizip I (aktiv, istovremeno)

```
der Hund, der bellt          → der bellende Hund
die Frau, die singt          → die singende Frau
das Kind, das spielt         → das spielende Kind
die Preise, die steigen      → die steigenden Preise
```

### Partizip II (passiv, završeno)

```
das Haus, das gebaut wurde   → das gebaute Haus
der Brief, der geschrieben wurde → der geschriebene Brief
die Waren, die beschädigt wurden → die beschädigten Waren
```

**Detaljna transformacija:** → [02-transformation.md](02-transformation.md)

## Primeri iz novina i akademskog pisanja

```
Die steigende Arbeitslosigkeit ist ein ernstes Problem.
→ Rastuća nezaposlenost je ozbiljan problem.

Das neu gegründete Unternehmen beschäftigt 500 Mitarbeiter.
→ Novoosnovana kompanija zapošljava 500 radnika.

Die von der Regierung beschlossenen Maßnahmen treten morgen in Kraft.
→ Mere koje je vlada usvojila stupaju na snagu sutra.

Der aus Deutschland stammende Wissenschaftler erhielt den Nobelpreis.
→ Naučnik poreklom iz Nemačke dobio je Nobelovu nagradu.

Die in den 1980er Jahren erbaute Brücke wird renoviert.
→ Most izgrađen 1980-ih se renovira.
```

---

## Sažetak: Partizip I vs Partizip II

| | Partizip I | Partizip II |
|---|---|---|
| Tvorba | Infinitiv + -d + nastavak | ge- + koren + -t/-en + nastavak |
| Značenje | aktiv, istovremeno | passiv (ili perf. aktiv), završeno |
| Primer | das laufende Kind | das gebaute Haus |
| Relativna rečenica | das Kind, das läuft | das Haus, das gebaut wurde |
