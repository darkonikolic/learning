# Pasiv — Predlozi: von, durch, mit

**Nivo:** B1–B2

U pasivnim rečenicama vršilac radnje ili sredstvo kojim se radnja vrši mogu biti navedeni uz pomoć određenih predloga. Svaki predlog ima drugačije značenje.

---

## von + Dativ — vršilac radnje

`von` se koristi kada je vršilac **osoba** ili **uzrok koji se ponaša kao agent** (institucija, prirodna sila koja se personifikuje).

*Das Buch wurde von dem Autor geschrieben.* — Knjigu je napisao autor.

*Das Kind wird von der Mutter getröstet.* — Dete teši majka.

*Die Stadt wurde von einem Erdbeben zerstört.* — Grad je razorio zemljotres.

*Der Brief wurde von meiner Kollegin unterschrieben.* — Pismo je potpisala moja koleginica.

*Die Musik wird von allen geliebt.* — Muziku svi vole.

**Konjugacija: von + Dativ**

| Род | Nominativ | Dativ uz von |
|---|---|---|
| muški | der Arzt | von dem Arzt / vom Arzt |
| ženski | die Lehrerin | von der Lehrerin |
| srednji | das Kind | von dem Kind / vom Kind |
| množina | die Eltern | von den Eltern |

---

## durch + Akkusativ — sredstvo ili posrednik

`durch` se koristi kada radnju ne vrši direktno osoba, nego **sredstvo, instrument, posrednik ili apstraktni uzrok**.

*Das Haus wurde durch einen Brand zerstört.* — Kuća je uništena požarom.

*Die Nachricht wurde durch die Presse verbreitet.* — Vest je preneta putem štampe.

*Er wurde durch einen Unfall verletzt.* — Povređen je u nesreći.

*Die Entscheidung wurde durch neue Informationen beeinflusst.* — Odluka je bila pod uticajem novih informacija.

*Die Brücke wurde durch starken Regen beschädigt.* — Most je oštećen jakim kišama.

**Razlika von vs durch:**

| | Primer | Značenje |
|---|---|---|
| von | *Das Fenster wurde von ihm eingeschlagen.* | On je razbio prozor (direktan vršilac) |
| durch | *Das Fenster wurde durch den Sturm eingeschlagen.* | Oluja je razbila prozor (sila, ne osoba) |

---

## mit + Dativ — instrument ili alat

`mit` se koristi kada se govori o **konkretnom alatu, instrumentu ili načinom** kojim se radnja vrši. Vršilac se ne navodi.

*Das Fleisch wird mit einem scharfen Messer geschnitten.* — Meso se seče oštrim nožem.

*Die Wände werden mit weißer Farbe gestrichen.* — Zidovi se farbaju belom bojom.

*Das Paket wurde mit Klebeband versiegelt.* — Paket je zalepljen selotejpom.

*Die Wunde wurde mit einem Verband behandelt.* — Rana je tretirana zavojem.

*Das Brot wird mit Butter bestrichen.* — Hleb se maže puterom.

---

## Pregled: von, durch, mit

| Predlog | Pitanje | Primer |
|---|---|---|
| von + Dativ | Ko vrši radnju? (osoba/agent) | *von dem Lehrer* |
| durch + Akkusativ | Čime/kako? (uzrok, posrednik) | *durch den Sturm* |
| mit + Dativ | Kojim alatom/instrumentom? | *mit dem Hammer* |

---

## Kada se vršilac izostavlja

U većini pasivnih rečenica vršilac se **ne navodi** — to je zapravo glavni razlog zašto se pasiv i koristi.

Vršilac se izostavlja kada:

1. **Nije poznat** — ne zna se ko je uradio
2. **Nije važan** — bitna je samo radnja
3. **Podrazumeva se** iz konteksta
4. **Govori se uopšteno** o radnjama

*Das Auto wurde gestohlen.* — Auto je ukradeno. (ne zna se ko)

*Hier wird Deutsch gesprochen.* — Ovde se govori nemački. (uopšteno)

*Die Prüfung wird morgen geschrieben.* — Sutra se piše ispit. (podrazumeva se ko)

*Die Straße wird repariert.* — Ulica se popravlja. (nevažno ko)

Istraživanja pokazuju da se vršilac navodi u samo oko 15–20% pasivnih rečenica u nemačkom.
