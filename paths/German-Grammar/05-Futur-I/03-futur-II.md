# Futur II

**Nivo:** B2


Futur II opisuje radnju koja će biti **završena u budućnosti** pre neke druge buduće radnje — ili pretpostavku o prošlosti. Retko se koristi u svakodnevnom govoru, ali se redovno pojavljuje na B2 ispitima.

---

## Struktura Futura II

```
werden (konjugovano) + Partizip II + haben / sein (infinitiv)
```

```
Ich werde das gemacht haben.
     ↑ 2. mesto    P.II  ↑ haben/sein na kraju
```

| Tip | Primer | Prevod |
|-----|--------|--------|
| haben-glagol | Ich **werde** es **gemacht haben**. | Biću to uradio/la. |
| sein-glagol | Er **wird** nach Hause **gegangen sein**. | Biće otišao kući. |
| haben-glagol | Sie **wird** das Buch **gelesen haben**. | Biće pročitala tu knjigu. |

---

## Konjugacija — primeri

**lernen** (Futur II, haben) · `werde gelernt haben / wirst gelernt haben / wird gelernt haben / werden gelernt haben / werdet gelernt haben / werden gelernt haben`

**gehen** (Futur II, sein) · `werde gegangen sein / wirst gegangen sein / wird gegangen sein / werden gegangen sein / werdet gegangen sein / werden gegangen sein`

---

## Kada se koristi Futur II

### 1. Radnja završena pre neke druge buduće radnje — uz bis

```
Bis morgen werde ich das erledigt haben.
→ Do sutra ću biti završio/la to.

Bis nächste Woche werden wir angekommen sein.
→ Do sledeće nedelje ćemo biti stigli.

Wenn du ankommst, werde ich schon gegessen haben.
→ Kada stigneš, ja ću već biti pojeo/la.
```

### 2. Pretpostavka o prošlosti (verovatno se desilo)

```
Er wird krank gewesen sein.
→ Verovatno je bio bolestan.

Sie wird das vergessen haben.
→ Verovatno je to zaboravila.

Das wird ein Fehler gewesen sein.
→ To je verovatno bila greška.
```

> Ova upotreba je česta u pisanom jeziku i na ispitima. Modifikatori kao *wohl*, *wahrscheinlich*, *sicher* pojačavaju pretpostavku.

---

## Sporedna rečenica

U sporednoj rečenici *werden* ide na kraj, iza Partizipa II i *haben/sein*:

```
Ich hoffe, dass er bis dann angekommen sein wird.
                                           ↑ werden na kraju
```

---

## Poređenje svih futurskih oblika

| Vreme | Struktura | Primer | Srpski |
|-------|-----------|--------|--------|
| Präsens (plan) | konjugovani glagol | Ich fahre morgen. | Putujem sutra. |
| Futur I | werden + Inf. | Ich werde fahren. | Putovati ću. |
| Futur II | werden + P.II + haben/sein | Ich werde gefahren sein. | Biću putovao/la. |
