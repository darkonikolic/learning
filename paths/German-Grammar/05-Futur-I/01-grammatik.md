# Futur I — Gramatika

**Nivo:** A2


Futur I se gradi sa *werden* + infinitiv i koristi se za planove, predviđanja i pretpostavke. U govornom jeziku se često zamenjuje Präsensom — ali Futur I ostaje neophodan za određene kontekste.

---

## Kada se koristi Futur I

| Upotreba | Primer | Prevod |
|----------|--------|--------|
| Plan / namera | Ich **werde** morgen **lernen**. | Sutra ću učiti. |
| Predviđanje | Es **wird** regnen. | Padaće kiša. |
| Pretpostavka u sadašnjosti | Er **wird** jetzt zu Hause **sein**. | Verovatno je sada kod kuće. |
| Obećanje | Ich **werde** das nicht vergessen. | Neću to zaboraviti. |
| Upozorenje | Du **wirst** das bereuen. | Požalićeš to. |

---

## Struktura Futura I

```
werden (konjugovano, 2. mesto) + ... + infinitiv (kraj rečenice)
```

```
Ich werde morgen nach Berlin fahren.
     ↑ 2. mesto                ↑ kraj (infinitiv)

Morgen werde ich nach Berlin fahren.
       ↑ 2. mesto (inverzija)  ↑ kraj
```

---

## Konjugacija werden (podsetnik)

**werden** · postati / ću · `werde / wirst / wird / werden / werdet / werden`

---

## Red reči s modalnim glagolima i Futurom

Kada se koristi i modalni i Futur (retko, ali moguće), infinitiv modalnog ide na kraj:

```
Er wird das schaffen können.
→ On će to moći da uradi.

Ich werde kommen müssen.
→ Moraću da dođem.
```

Redosled na kraju: **sadržajni infinitiv + modalni infinitiv** (Ersatzinfinitiv).

---

## Negacija u Futuru I

*nicht* dolazi ispred infinitiva (ili iza objekta):

```
Ich werde das nicht machen.      → Neću to uraditi.
Er wird nicht kommen.            → Neće doći.
Wir werden kein Geld haben.      → Nećemo imati novca.
```

---

## Pitanja u Futuru I

### Da/Ne pitanje — werden na 1. mesto

```
Wirst du kommen?            → Hoćeš li doći?
Wird es regnen?             → Hoće li padati kiša?
Werden sie feiern?          → Hoće li slaviti?
```

### W-pitanje — W-reč na 1., werden na 2. mesto

```
Wann wirst du ankommen?     → Kada ćeš stići?
Was wirst du machen?        → Šta ćeš raditi?
Wohin werden sie fahren?    → Kuda će putovati?
```

---

## Futur s refleksivnim glagolima

Zamenica *sich* dolazi posle konjugovanog *werden*:

```
Ich werde mich beeilen.         → Žuriću se.
Er wird sich freuen.            → Obradovaće se.
Wir werden uns treffen.         → Srešćemo se.
```

---

## Sporedna rečenica — werden na kraj

```
Ich glaube, dass er kommen wird.
                          ↑ werden ide na kraj u sporednoj rečenici

Ich hoffe, dass es nicht regnen wird.
→ Nadam se da neće padati kiša.
```
