# Bestimmter Artikel — Određeni član (der, die, das)

**Nivo:** A1


Određeni član u nemačkom odgovara srpskom "taj/ta/to" ili "ovaj/ova/ovo". Svaka imenica ima **rod** (muški, ženski ili srednji), koji se mora naučiti zajedno s imenicom.

---

## der / die / das / die

| Rod | Član | Primer | Srpski |
|-----|------|--------|--------|
| muški (Maskulinum) | **der** | der Mann | (taj) muškarac |
| ženski (Femininum) | **die** | die Frau | (ta) žena |
| srednji (Neutrum) | **das** | das Kind | (to) dete |
| množina (svi rodovi) | **die** | die Kinder | (ta) deca |

> Nema pravila koje pokriva sve reči — rod se uči napamet uz svaku imenicu. Ipak, postoje **nastavci koji signalizuju rod**.

---

## Zašto postoji rod u nemačkom?

Rod imenica u nemačkom nije biološki (mada često jeste) — on je **gramatička kategorija**. Rod utiče na oblik člana, prideva i zamenica u rečenici.

```
Das Mädchen ist klug.   → das (srednji) — iako je devojčica
Das Messer ist scharf.  → das (srednji) — nož
Der Tisch ist groß.     → der (muški) — sto
```

---

## Pravila za prepoznavanje roda po nastavku

### Muški rod (der) — česti nastavci

| Nastavak | Primeri |
|----------|---------|
| **-er** (vršilac radnje) | der Lehrer, der Fahrer, der Bäcker |
| **-ismus** | der Kapitalismus, der Tourismus |
| **-or** | der Doktor, der Motor |
| **-ant** | der Student (izuzetak: das), der Praktikant |
| dani, meseci, godišnja doba | der Montag, der Januar, der Sommer |

### Ženski rod (die) — česti nastavci

| Nastavak | Primeri |
|----------|---------|
| **-ung** | die Wohnung, die Zeitung, die Übung |
| **-heit** | die Freiheit, die Gesundheit, die Schönheit |
| **-keit** | die Möglichkeit, die Schwierigkeit |
| **-schaft** | die Freundschaft, die Gesellschaft |
| **-tion** | die Nation, die Situation, die Information |
| **-tät** | die Universität, die Qualität |
| **-ik** | die Musik, die Politik, die Grammatik |
| **-in** (ženski vršilac) | die Lehrerin, die Ärztin |
| **-ie** | die Energie, die Demokratie |

### Srednji rod (das) — česti nastavci

| Nastavak | Primeri |
|----------|---------|
| **-chen** | das Mädchen, das Häuschen |
| **-lein** | das Büchlein, das Männlein |
| **-ment** | das Dokument, das Instrument |
| **-um** | das Datum, das Zentrum, das Museum |
| **-tum** | das Eigentum, das Wachstum |
| **Ge-** (kolektivi) | das Gemüse, das Gebäude, das Gespräch |
| infinitivi kao imenice | das Lernen, das Lesen, das Schreiben |

## Nominativ tabela

| Rod | Određeni član |
|-----|---------------|
| Maskulinum (m.) | **der** |
| Femininum (f.) | **die** |
| Neutrum (n.) | **das** |
| Plural | **die** |

---

## Česti izuzeci (uče se napamet)

| Imenica | Rod | Napomena |
|---------|-----|----------|
| das Mädchen | das | -chen uvek srednji, bez obzira na značenje |
| das Weib | das | žena (arhaično) — srednji rod |
| der See | der | jezero — izuzetak (ali: die See = more) |
| das Meer | das | more |
