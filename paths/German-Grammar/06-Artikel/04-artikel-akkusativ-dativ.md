# Član u Akkuzativu i Dativu

**Nivo:** A2


Nemački ima četiri padeža. Na A2 nivou su najvažnija tri: **Nominativ**, **Akkuzativ** i **Dativ**. Genitiv dolazi na B1 (zasebni fajl).

---

## Koja pitanja — koji padež

| Pitanje | Padež | Uloga | Primer |
|---------|-------|-------|--------|
| Wer? / Was? | **Nominativ** | subjekat | **Der Mann** kommt. |
| Wen? / Was? | **Akkuzativ** | direktni objekat | Ich sehe **den Mann**. |
| Wem? | **Dativ** | indirektni objekat | Ich helfe **dem Mann**. |

---

## Bestimmter Artikel — Određeni član u svim padežima

| Padež | Maskulinum | Femininum | Neutrum | Plural |
|-------|------------|-----------|---------|--------|
| Nominativ | **der** | **die** | **das** | **die** |
| Akkuzativ | **den** | **die** | **das** | **die** |
| Dativ | **dem** | **der** | **dem** | **den** |
| Genitiv | **des** | **der** | **des** | **der** |

> Promena je samo u **muškom rodu**: Nominativ *der* → Akkuzativ *den* → Dativ *dem*
> Ženski rod: Nominativ/Akkuzativ *die*, ali Dativ **der**

---

## Unbestimmter Artikel — Neodređeni član u svim padežima

| Padež | Maskulinum | Femininum | Neutrum | Plural |

## Primeri sa svim padežima

### Maskulinum — der Mann

```
Nominativ:   Der Mann ist nett.             → Muškarac je ljubazan.
Akkuzativ:   Ich sehe den Mann.             → Vidim muškarca.
Dativ:       Ich helfe dem Mann.            → Pomažem muškarcu.
```

### Femininum — die Frau

```
Nominativ:   Die Frau ist hier.             → Žena je ovde.
Akkuzativ:   Ich sehe die Frau.             → Vidim ženu.
Dativ:       Ich gebe der Frau das Buch.    → Dajem ženi tu knjigu.
```

### Neutrum — das Kind

```
Nominativ:   Das Kind schläft.              → Dete spava.
Akkuzativ:   Ich sehe das Kind.             → Vidim dete.
Dativ:       Ich gebe dem Kind ein Buch.    → Dajem detetu knjigu.
```

### Plural — die Kinder

```
Nominativ:   Die Kinder spielen.            → Deca se igraju.
Akkuzativ:   Ich sehe die Kinder.           → Vidim decu.
Dativ:       Ich gebe den Kindern Äpfel.    → Dajem deci jabuke. (+n u Dativu pl.)
```

## Prepozicije koje zahtevaju određeni padež

### Uvek Akkuzativ

| Prepozicija | Srpski |
|-------------|--------|
| durch | kroz |
| für | za |
| gegen | protiv |
| ohne | bez |
| um | oko, u (vreme) |
| bis | do |
| entlang | duž |

```
Ich kaufe das für den Mann.      → Kupujem to za muškarca.
Er geht durch den Park.          → Ide kroz park.
```

### Uvek Dativ

| Prepozicija | Srpski |
|-------------|--------|
| aus | iz |
| bei | kod, pri |
| mit | sa |
| nach | posle, ka (gradu) |
| seit | od (vremena) |
| von | od |
| zu | ka, kod |
| gegenüber | nasuprot |
| außer | osim |

```
Ich fahre mit dem Bus.           → Vozim se autobusom.
Er kommt aus dem Haus.           → Izlazi iz kuće.
Ich gehe zu dem (= zum) Arzt.   → Idem kod lekara.
```

### Wechselpräpositionen — Dativ ili Akkuzativ (9 prepozicija)

Uz: *an, auf, hinter, in, neben, über, unter, vor, zwischen*

| Pitanje | Padež | Primer |
|---------|-------|--------|
| Wo? (gde — stanje) | **Dativ** | Das Buch liegt **auf dem** Tisch. |
| Wohin? (kuda — kretanje) | **Akkuzativ** | Ich lege das Buch **auf den** Tisch. |

```
Wo?    Das Buch ist in der Tasche.    → Knjiga je u torbi. (Dativ)
Wohin? Ich lege das Buch in die Tasche. → Stavljam knjigu u torbu. (Akkuzativ)
```

---

## Skraćenice (kontrakcije)

| Prepozicija + član | Kontrakcija |
|-------------------|-------------|
| an + dem | **am** |
| an + das | **ans** |
| bei + dem | **beim** |
| in + dem | **im** |
| in + das | **ins** |
| von + dem | **vom** |
| zu + dem | **zum** |
| zu + der | **zur** |

```
Ich gehe zum Arzt.           = zu dem Arzt
Er ist im Kino.              = in dem Kino
Sie fährt ans Meer.          = an das Meer
```
