# Jaki glagoli (Starke Verben)

**Nivo:** A1–B2


Nepravilni glagoli — **samoglasnik u korenu se menja** kod *du* i *er/sie/es*.

Promena je samo u Präsens; drugačije promene dolaze u Präteritumu i Perfektu.

## Obrasci promene samoglasnika

### e → i

**sprechen** · govoriti · `spreche / sprichst / spricht / sprechen / sprecht / sprechen`

**geben** · davati · `gebe / gibst / gibt / geben / gebt / geben`

**nehmen** · uzimati · `nehme / nimmst / nimmt / nehmen / nehmt / nehmen`

**helfen** · pomagati · `helfe / hilfst / hilft / helfen / helft / helfen`

**werfen** · bacati · `werfe / wirfst / wirft / werfen / werft / werfen`

**treffen** · sresti · `treffe / triffst / trifft / treffen / trefft / treffen`

**essen** · jesti · `esse / isst / isst / essen / esst / essen`

**vergessen** · zaboraviti · `vergesse / vergisst / vergisst / vergessen / vergesst / vergessen`

### e → ie

**lesen** · čitati · `lese / liest / liest / lesen / lest / lesen`

**sehen** · videti · `sehe / siehst / sieht / sehen / seht / sehen`

**stehlen** · krasti · `stehle / stiehlst / stiehlt / stehlen / stehlt / stehlen`

**empfehlen** · preporučiti · `empfehle / empfiehlst / empfiehlt / empfehlen / empfehlt / empfehlen`

### a → ä

**fahren** · voziti, putovati · `fahre / fährst / fährt / fahren / fahrt / fahren`

**schlafen** · spavati · `schlafe / schläfst / schläft / schlafen / schlaft / schlafen`

**tragen** · nositi · `trage / trägst / trägt / tragen / tragt / tragen`

**fallen** · padati · `falle / fällst / fällt / fallen / fallt / fallen`

**halten** · držati, stati · `halte / hältst / hält / halten / haltet / halten`

**lassen** · pustiti, ostaviti · `lasse / lässt / lässt / lassen / lasst / lassen`

**waschen** · prati · `wasche / wäschst / wäscht / waschen / wascht / waschen`

**wachsen** · rasti · `wachse / wächst / wächst / wachsen / wachst / wachsen`

**schlagen** · udarati · `schlage / schlägst / schlägt / schlagen / schlagt / schlagen`

### au → äu

**laufen** · trčati, hodati · `laufe / läufst / läuft / laufen / lauft / laufen`

## Posebni jaki glagoli (bez jasnog obrasca)

**kommen** · dolaziti · `komme / kommst / kommt / kommen / kommt / kommen`

**stehen** · stajati · `stehe / stehst / steht / stehen / steht / stehen`

**heißen** · zvati se · `heiße / heißt / heißt / heißen / heißt / heißen`

**bleiben** · ostati · `bleibe / bleibst / bleibt / bleiben / bleibt / bleiben`

**schreiben** · pisati · `schreibe / schreibst / schreibt / schreiben / schreibt / schreiben`

**trinken** · piti · `trinke / trinkst / trinkt / trinken / trinkt / trinken`

**beginnen** · početi · `beginne / beginnst / beginnt / beginnen / beginnt / beginnen`

**gewinnen** · pobediti · `gewinne / gewinnst / gewinnt / gewinnen / gewinnt / gewinnen`

**finden** · naći, smatrati · `finde / findest / findet / finden / findet / finden`

**binden** · vezati · `binde / bindest / bindet / binden / bindet / binden`

## Čest ispitni glagol: nehmen

*nehmen* ima dvostruku promenu: **e → i** i **mm** u korenu:

```
ich nehme, du nimmst, er nimmt, wir nehmen, ihr nehmt, sie nehmen
```

## Čest ispitni glagol: lassen

*lassen* se često koristi kao semi-modal ("pustiti nekoga da"):

```
Ich lasse ihn gehen.   → Puštam ga da ide.
Er lässt das Handy zu. → Ostavlja telefon isključenim.
```

## Jaki glagoli koji su i razdvojivi

Kod razdvojivih jakih glagola važi **oba** pravila — menja se samoglasnik I prefiks se odvaja:

| Infinitiv | du | er/sie/es | Prevod |
|-----------|-----|-----------|--------|
| einladen | **lädst** ein | **lädt** ein | pozivati |
| anfangen | **fängst** an | **fängt** an | počinjati |
| aufnehmen | **nimmst** auf | **nimmt** auf | snimiti, prihvatiti |
| vorsehen | **siehst** vor | **sieht** vor | predviđati |
| vorhaben | hat vor (haben→hat) | hat vor | planirati, nameravati |

## Pregled obrazaca — quick reference

| Promena | Glagoli |
|---------|---------|
| e → i | sprechen, geben, nehmen, helfen, treffen, werfen, essen, vergessen |
| e → ie | lesen, sehen, empfehlen, stehlen |
| a → ä | fahren, schlafen, tragen, fallen, halten, lassen, waschen |
| au → äu | laufen |
| bez promene u Präsens | kommen, stehen, bleiben, schreiben, trinken, beginnen |
