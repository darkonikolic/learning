# Slabi glagoli (Schwache Verben)

**Nivo:** A1–B2


Pravilni glagoli — **koren se ne menja**, dodaju se samo nastavci.

```
machen → mach- + -e / -st / -t / -en / -t / -en
```

Za nastavke → [01-grammatik.md](01-grammatik.md)

## Glagoli s korenom na -d, -t, -m, -n — umeće se **-e-**

**arbeiten** · raditi · `arbeite / arbeitest / arbeitet / arbeiten / arbeitet / arbeiten`

**antworten** · odgovarati · `antworte / antwortest / antwortet / antworten / antwortet / antworten`

**öffnen** · otvoriti · `öffne / öffnest / öffnet / öffnen / öffnet / öffnen`

**warten** · čekati · `warte / wartest / wartet / warten / wartet / warten`

## Glagoli s korenom na -s, -ß, -z — *du* dobija samo **-t** (ne -st)

| Infinitiv | du |
|-----------|-----|
| heißen | heiß**t** |
| tanzen | tanz**t** |
| reisen | reis**t** |
| sitzen | sitz**t** |

## Pravilo za glagole na -ieren (B1/B2)

Svi glagoli na **-ieren** su slabi i naglasak je uvek na **-ie-**:

```
studieren → ich studiere, du studierst, er studiert
```

Nema promene samoglasnika, nema umetanja -e-. Uvek pravilni.
