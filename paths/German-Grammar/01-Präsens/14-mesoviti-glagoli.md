# Mešoviti glagoli (Gemischte Verben)

**Nivo:** A2–B1

Glagoli koji kombinuju karakteristike slabih i jakih:
- uzimaju **slabe nastavke** (kao *machen*: -e, -st, -t, -en, -t, -en)
- ali menjaju **samoglasnik ili suglasnik u korenu** (kao jaki glagoli)

U Präsensu se ponašaju **kao slabi** — koren se ne menja.

---

## Lista mešovitih glagola

**denken** · misliti · `denke / denkst / denkt / denken / denkt / denken`

**bringen** · doneti, nositi · `bringe / bringst / bringt / bringen / bringt / bringen`

**kennen** · poznavati · `kenne / kennst / kennt / kennen / kennt / kennen`

**nennen** · nazivati · `nenne / nennst / nennt / nennen / nennt / nennen`

**rennen** · trčati (brzo) · `renne / rennst / rennt / rennen / rennt / rennen`

**brennen** · goreti · `brenne / brennst / brennt / brennen / brennt / brennen`

**wissen** · znati (činjenicom) · `weiß / weißt / weiß / wissen / wisst / wissen`

**senden** · slati (signal, poruku) · `sende / sendest / sendet / senden / sendet / senden`

**wenden** · okrenuti, obratiti se · `wende / wendest / wendet / wenden / wendet / wenden`

---

## Poseban slučaj — wissen

*wissen* ima nepravilan Präsens (ich/er = **weiß**, bez nastavka — kao modalni):

`weiß / weißt / weiß / wissen / wisst / wissen`

Za razliku wissen vs kennen → [06-wissen-kennen.md](06-wissen-kennen.md)
