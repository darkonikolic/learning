# Refleksivni glagoli (Reflexive Verben)

**Nivo:** A2–B2


Glagoli koji zahtevaju **povratnu zamenicu** (mich, dich, sich, uns, euch, sich).

```
Ich wasche mich.     → Perem se.
Er freut sich.       → On se raduje.
```

---

## Povratne zamenice (Reflexivpronomen)

| Lice | Akuzativ | Dativ |
|------|----------|-------|
| ich | **mich** | **mir** |
| du | **dich** | **dir** |
| er/sie/es | **sich** | **sich** |
| wir | **uns** | **uns** |
| ihr | **euch** | **euch** |
| sie/Sie | **sich** | **sich** |

Većina refleksivnih glagola ide s **akuzativom**. Dativ se koristi kad postoji još jedan objekat u rečenici.

```
Ich wasche mich.          → Akuzativ (samo jedna radnja)
Ich wasche mir die Hände. → Dativ (ruke = objekat u Akuzativu)
```

## Pravila za ispit

### 1. Povratna zamenica dolazi odmah posle glagola (u izjavnoj rečenici)

```
Ich freue mich.        ✓
Ich mich freue.        ✗
```

### 2. S modalnim glagolom — zamenica ostaje uz glagol

```
Ich muss mich beeilen.          ✓
Du musst dich anmelden.         ✓
```

### 3. U pitanjima

```
Freust du dich?         ✓
Wo befindet sich das Hotel? ✓
```

### 4. Dativ uz drugi objekat

```
Ich kaufe mir ein Buch.         → (mir = Dativ, Buch = Akuzativ)
Du putzt dir die Zähne.         → (dir = Dativ, Zähne = Akuzativ)
Er wäscht sich die Hände.       → (sich = Dativ, Hände = Akuzativ)
```

## Glagoli koji mogu biti i refleksivni i nefleksivni

Neki glagoli menjaju značenje sa ili bez *sich*:

| Bez sich | Sa sich | Razlika |
|----------|---------|---------|
| Er wäscht das Auto. | Er wäscht sich. | On pere auto. / On se pere. |
| Ich ziehe das Kind an. | Ich ziehe mich an. | Oblačim dete. / Oblačim se. |
| Er trifft seinen Freund. | Wir treffen uns. | Sreće prijatelja. / Srećemo se. |
| Ich freue das Kind. | Ich freue mich. | Radujem dete. / Radujem se. |
