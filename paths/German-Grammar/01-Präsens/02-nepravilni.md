# Nepravilni glagoli — sein, haben, werden

**Nivo:** A1


Ova tri glagola **ne prate nikakav obrazac** — svaki oblik se uči napamet.

Najvažniji su glagoli u celom nemačkom: koriste se i samostalno i kao **pomoćni glagoli** za složena vremena.

---

## sein — biti

**sein** · biti · `bin / bist / ist / sind / seid / sind`

### Primeri

| Nemački | Srpski |
|---------|--------|
| Ich **bin** Darko. | Ja sam Darko. |
| **Wer bist** du? | Ko si ti? |
| Er **ist** aus Serbien. | On je iz Srbije. |
| Wir **sind** Freunde. | Mi smo prijatelji. |
| Das **ist** kein Problem. | To nije problem. |
| Wie alt **bist** du? | Koliko imaš godina? |

### Kao pomoćni glagol

*sein* se koristi za Perfekt glagola kretanja i promene stanja:

```
Ich bin gefahren.   → Vozio/la sam se.
Er ist gegangen.    → Otišao je.
Sie ist aufgewacht. → Probudila se.
```

---

## haben — imati

**haben** · imati · `habe / hast / hat / haben / habt / haben`

### Primeri

| Nemački | Srpski |
|---------|--------|
| Ich **habe** Zeit. | Imam vremena. |
| **Hast** du ein Buch? | Imaš li knjigu? |
| Er **hat** Hunger. | Gladan je. (dosl. ima glad) |
| Wir **haben** keine Ahnung. | Nemamo pojma. |
| Sie **hat** Recht. | Ona ima pravo. |
| **Habt** ihr Fragen? | Imate li pitanja? |

### Česti izrazi s haben (A1–B2)

| Izraz | Srpski |
|-------|--------|
| Hunger haben | biti gladan |
| Durst haben | biti žedan |
| Angst haben | bojati se |
| Recht haben | imati pravo |
| Zeit haben | imati vremena |
| Lust haben | imati volju za nešto |
| Interesse haben | biti zainteresovan |
| Schmerzen haben | bolan biti, imati bolove |

### Kao pomoćni glagol

*haben* se koristi za Perfekt većine glagola:

```
Ich habe gelernt.   → Učio/la sam.
Er hat gegessen.    → Jeo je.
Wir haben gemacht.  → Radili smo.
```

---

## werden — postati / (futurski pomoćni)

**werden** · postati / ću · `werde / wirst / wird / werden / werdet / werden`

### Primeri — samostalno (postati)

| Nemački | Srpski |
|---------|--------|
| Er **wird** Arzt. | On postaje lekar. |
| Du **wirst** müde. | Postaješ umoran/na. |
| Es **wird** dunkel. | Smrkava se. |
| Sie **wird** besser. | Ona se oporavlja (postaje bolje). |

### Kao pomoćni glagol — Futur I

```
Ich werde lernen.       → Učiću.
Er wird kommen.         → Doći će.
Wir werden feiern.      → Slavićemo.
```

### Kao pomoćni glagol — Passiv (B1/B2)

```
Das Buch wird gelesen.       → Knjiga se čita.
Das Haus wird gebaut.        → Kuća se gradi.
Die Prüfung wird vorbereitet.→ Ispit se priprema.
```

---

## Poređenje sein / haben / werden

| | sein | haben | werden |
|--|------|-------|--------|
| **Značenje** | biti | imati | postati / (ću) |
| **Perfekt s.v.** | ist gewesen | hat gehabt | ist geworden |
| **Futur I** | wird sein | wird haben | wird werden |
| **Passiv** | — | — | wird gemacht |

---

## Greške koje treba izbegavati

| Greška | Ispravno | Objašnjenje |
|--------|----------|-------------|
| ~~Ich bin 25 Jahre.~~ | Ich **bin** 25 Jahre **alt**. | *alt* se ne izostavlja |
| ~~Ich habe kalt.~~ | Mir **ist** kalt. | osećaj temperature → *sein* |
| ~~Ich habe hunger.~~ | Ich habe **Hunger**. | imenica → veliko slovo |
| ~~Er wird müde.~~ | Er **ist** müde. | stanje (ne promena) → *sein* |
