# Glagoli s fiksnim prepozicijama (Verben mit festen Präpositionen)

**Nivo:** B1–B2


Određeni glagoli uvek idu s **istom prepozicijom** — ta veza je fiksna i uči se napamet.

Prepozicija određuje **padež** (Akkusativ ili Dativ).

---

## Zašto je ovo važno za ispit

Na B1/B2 ispitu pitanja tipa "Ich warte ___ den Bus" ili "Er fragt ___ dem Weg" direktno testiraju ove veze. Pogrešna prepozicija = pogrešan odgovor.

---

## Glagoli s **auf + Akkusativ**

| Glagol | Srpski | Primer |
|--------|--------|--------|
| warten auf | čekati na | Ich warte **auf** den Bus. |
| freuen sich auf | radovati se (nečemu što dolazi) | Ich freue mich **auf** den Urlaub. |
| hoffen auf | nadati se | Er hofft **auf** eine Antwort. |
| antworten auf | odgovoriti na | Sie antwortet **auf** die Frage. |
| reagieren auf | reagovati na | Er reagiert **auf** die Nachricht. |
| sich vorbereiten auf | pripremati se za | Ich bereite mich **auf** die Prüfung vor. |
| achten auf | paziti na | Achte **auf** die Zeit! |
| verzichten auf | odreći se | Er verzichtet **auf** Fleisch. |
| sich beziehen auf | odnositi se na | Das bezieht sich **auf** das erste Kapitel. |
| bestehen auf | insistirati na | Er besteht **auf** einer Erklärung. |

## Freuen się — dve prepozicije, dva značenja

Ovo je česta greška na ispitu:

| | Prepozicija | Značenje | Primer |
|--|------------|---------|--------|
| **sich freuen auf** | auf + Akk | radovati se **nečemu što tek dolazi** | Ich freue mich **auf** die Party. |
| **sich freuen über** | über + Akk | radovati se **zbog nečega što se desilo** | Ich freue mich **über** das Geschenk. |

---

## Pitanje o prepozicijskom objektu — Wofür / Worüber / Worauf...

Kad je objekat **stvar** (ne osoba), pitanje se gradi sa **wo(r)- + prepozicija**:

| Prepozicija | Pitanje za stvar | Pitanje za osobu |
|------------|----------------|-----------------|
| auf | wor**auf** | auf **wen** |
| über | wor**über** | über **wen** |
| an | wor**an** | an **wen** |
| für | wof**ür** | für **wen** |
| mit | wom**it** | mit **wem** |
| von | wov**on** | von **wem** |

```
Worauf wartest du?       → Auf den Bus.      (stvar)
Auf wen wartest du?      → Auf meinen Freund. (osoba)

Wofür interessierst du dich?  → Für Musik.
Für wen kaufst du das?        → Für meine Mutter.
```
