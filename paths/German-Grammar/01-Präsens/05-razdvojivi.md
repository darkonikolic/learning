# Razdvojivi glagoli (Trennbare Verben)

**Nivo:** A1–B2


Glagoli sa prefiksom koji se **odvaja** u rečenici i ide na **kraj**.

```
aufmachen → Ich mache die Tür auf.
             ↑ glagol (2. mesto)      ↑ prefiks (kraj)
```

Infinitiv je jedno: *aufmachen*. U rečenici se razdvaja: *mache ... auf*.

---

## Česti razdvojivi prefiksi

| Prefiks | Značenje | Primer |
|---------|----------|--------|
| ab- | odlazak, odvajanje | abfahren (otputovati) |
| an- | početak, pristupanje | anfangen (početi) |
| auf- | gore, otvaranje | aufmachen (otvoriti) |
| aus- | izlazak, gašenje | ausgehen (izaći) |
| bei- | pridruživanje | beibringen (naučiti nekoga) |
| ein- | ulazak | einladen (pozvati) |
| mit- | zajedno | mitkommen (doći s nekim) |
| nach- | za, posle | nachschauen (proveriti) |
| vor- | ispred, pre | vorstellen (predstaviti) |
| zu- | zatvaranje, pribavljanje | zumachen (zatvoriti) |
| zurück- | natrag | zurückkommen (vratiti se) |
| weiter- | dalje | weitermachen (nastaviti) |

---

## Kompletna lista (A1–B2)

### A1

**aufmachen** · otvoriti · `mache auf / machst auf / macht auf / machen auf / macht auf / machen auf` · Ich mache das Fenster auf.

**zumachen** · zatvoriti · `mache zu / machst zu / macht zu / machen zu / macht zu / machen zu` · Er macht die Tür zu.

**anrufen** · pozvati telefonom · `rufe an / rufst an / ruft an / rufen an / ruft an / rufen an` · Ich rufe dich an.

**aufstehen** · ustati · `stehe auf / stehst auf / steht auf / stehen auf / steht auf / stehen auf` · Ich stehe um 7 auf.

**mitkommen** · doći zajedno · `komme mit / kommst mit / kommt mit / kommen mit / kommt mit / kommen mit` · Kommst du mit?

**abfahren** · otputovati, krenuti · `fahre ab / fährst ab / fährt ab / fahren ab / fahrt ab / fahren ab` · Der Zug fährt um 8 ab.

**ankommen** · stići · `komme an / kommst an / kommt an / kommen an / kommt an / kommen an` · Wann kommst du an?

### A2

**anmelden** · prijaviti · `melde an / meldest an / meldet an / melden an / meldet an / melden an` · Ich melde mich an.

**abmelden** · odjaviti · `melde ab / meldest ab / meldet ab / melden ab / meldet ab / melden ab` · Er meldet sich ab.

**abholen** · preuzeti, pokupiti · `hole ab / holst ab / holt ab / holen ab / holt ab / holen ab` · Ich hole dich ab.

**aufräumen** · pospremiti · `räume auf / räumst auf / räumt auf / räumen auf / räumt auf / räumen auf` · Ich räume das Zimmer auf.

**ausgehen** · izaći (van) · `gehe aus / gehst aus / geht aus / gehen aus / geht aus / gehen aus` · Wir gehen heute Abend aus.

**einkaufen** · kupovati, ići u kupovinu · `kaufe ein / kaufst ein / kauft ein / kaufen ein / kauft ein / kaufen ein` · Sie kauft jeden Tag ein.

**fernsehen** · gledati TV · `sehe fern / siehst fern / sieht fern / sehen fern / seht fern / sehen fern` · Er sieht jeden Abend fern.

**umziehen** · preseliti se / presvući se · `ziehe um / ziehst um / zieht um / ziehen um / zieht um / ziehen um` · Wir ziehen nächsten Monat um.

**einladen** · pozivati · `lade ein / lädst ein / lädt ein / laden ein / ladet ein / laden ein` · Ich lade dich ein.

**anfangen** · počinjati · `fange an / fängst an / fängt an / fangen an / fangt an / fangen an` · Wann fängt der Film an?

**aufhören** · prestati · `höre auf / hörst auf / hört auf / hören auf / hört auf / hören auf` · Hör auf!

**aufwachen** · buditi se · `wache auf / wachst auf / wacht auf / wachen auf / wacht auf / wachen auf` · Ich wache früh auf.

### B1

**vorbereiten** · pripremiti · `bereite vor / bereitest vor / bereitet vor / bereiten vor / bereitet vor / bereiten vor` · Ich bereite das Essen vor.

**aufgeben** · predati, odustati · `gebe auf / gibst auf / gibt auf / geben auf / gebt auf / geben auf` · Er gibt nicht auf.

**weitermachen** · nastaviti · `mache weiter / machst weiter / macht weiter / machen weiter / macht weiter / machen weiter` · Machen wir weiter!

**zusammenfassen** · sažeti · `fasse zusammen / fasst zusammen / fasst zusammen / fassen zusammen / fasst zusammen / fassen zusammen` · Kannst du das zusammenfassen?

**aufnehmen** · snimiti, primiti · `nehme auf / nimmst auf / nimmt auf / nehmen auf / nehmt auf / nehmen auf` · Er nimmt das Video auf.

**nachschauen** · proveriti, potražiti · `schaue nach / schaust nach / schaut nach / schauen nach / schaut nach / schauen nach` · Ich schaue es im Wörterbuch nach.

**vorstellen** · predstaviti · `stelle vor / stellst vor / stellt vor / stellen vor / stellt vor / stellen vor` · Ich stelle mich vor.

**teilnehmen** · učestvovati · `nehme teil / nimmst teil / nimmt teil / nehmen teil / nehmt teil / nehmen teil` · Er nimmt an dem Kurs teil.

**durchführen** · sprovesti · `führe durch / führst durch / führt durch / führen durch / führt durch / führen durch` · Wir führen den Plan durch.

**ausdrücken** · izraziti · `drücke aus / drückst aus / drückt aus / drücken aus / drückt aus / drücken aus` · Ich drücke mich aus.

### B2

**herausfinden** · otkriti, utvrditi · `finde heraus / findest heraus / findet heraus / finden heraus / findet heraus / finden heraus` · Ich finde heraus, was passiert ist.

**zurückgeben** · vratiti · `gebe zurück / gibst zurück / gibt zurück / geben zurück / gebt zurück / geben zurück` · Er gibt das Buch zurück.

**ankündigen** · najaviti · `kündige an / kündigst an / kündigt an / kündigen an / kündigt an / kündigen an` · Die Firma kündigt Entlassungen an.

**aufzeigen** · ukazati, prikazati · `zeige auf / zeigst auf / zeigt auf / zeigen auf / zeigt auf / zeigen auf` · Der Bericht zeigt Probleme auf.

**hervorheben** · istaknuti · `hebe hervor / hebst hervor / hebt hervor / heben hervor / hebt hervor / heben hervor` · Er hebt die wichtigsten Punkte hervor.

**zurückziehen** · povući · `ziehe zurück / ziehst zurück / zieht zurück / ziehen zurück / zieht zurück / ziehen zurück` · Er zieht den Antrag zurück.

## Pravila — što treba znati za ispit

### 1. Prefiks uvek na kraju

```
Ich rufe dich morgen an.      ✓
Ich anrufe dich morgen.       ✗
```

### 2. U pitanju — isti red

```
Rufst du mich an?             ✓
Wann fährt der Zug ab?        ✓
```

### 3. S modalnim glagolom — infinitiv je ceo (ne razdvojen)

```
Ich möchte dich anrufen.      ✓  (infinitiv = anrufen, ceo na kraju)
Ich möchte dich rufen an.     ✗
```

### 4. U sporednoj rečenici — infinitiv je ceo

```
Ich weiß, dass er anruft.     ✓  (sporedna → glagol na kraju, ali spojen)
```

## Nerazdvojivi prefiksi (za poređenje)

Prefiksi **be-, ge-, er-, ver-, zer-, ent-, emp-, miss-** se **nikad ne odvajaju**:

| Prefiks | Primer | Srpski |
|---------|--------|--------|
| be- | besuchen | posetiti |
| ver- | verstehen | razumeti |
| er- | erklären | objasniti |
| ent- | entschuldigen | izviniti |
| ge- | gehören | pripadati |
| zer- | zerstören | uništiti |
| miss- | missverstehen | pogrešno razumeti |

```
Ich besuche meinen Freund.     → nema razdvajanja
Ich verstehe das nicht.        → nema razdvajanja
```
