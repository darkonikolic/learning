# Imperativ (Zapovedno/zamolno glagolsko lice)

**Nivo:** A2–B1


Imperativ se koristi za **naloge, zahteve, savete, molbe**.

Gradi se od **Präsens korena** — zato spada u Präsens oblast.

---

## Tri oblika imperativa

| Lice | Kada se koristi | Primer |
|------|----------------|--------|
| **du** | jedna osoba, neformalno | Komm! |
| **ihr** | više osoba, neformalno | Kommt! |
| **Sie** | formalno (jedna ili više) | Kommen Sie! |

---

## Kako se pravi

### du-oblik

Koren glagola + (opcionalno **-e**):

```
kommen → Komm! (ili: Komme!)
lernen → Lern! (ili: Lerne!)
machen → Mach! (ili: Mache!)
```

> **-e** se često izostavlja u govoru, osim kad koren završava na -d, -t, -m, -n → obavezno **-e**:

```
arbeiten → Arbeit-e!     ← obavezno -e
antworten → Antwort-e!
öffnen → Öffn-e!
warten → Wart-e!
```

### ihr-oblik

= Präsens ihr forma bez "ihr":

```
Ihr kommt. → Kommt!
Ihr lernt. → Lernt!
Ihr macht. → Macht!
```

### Sie-oblik

= Präsens Sie forma + **Sie** ostaje, ali dolazi IZA glagola:

```
Sie kommen. → Kommen Sie!
Sie lernen. → Lernen Sie!
Sie machen. → Machen Sie!
```

---

## Jaki glagoli — e→i / e→ie promena važi i u imperativu (du)

| Infinitiv | Präsens du | Imperativ du |
|-----------|-----------|--------------|
| sprechen | sprichst | **Sprich!** |
| nehmen | nimmst | **Nimm!** |
| geben | gibst | **Gib!** |
| helfen | hilfst | **Hilf!** |
| lesen | liest | **Lies!** |
| sehen | siehst | **Sieh!** |
| essen | isst | **Iss!** |

> Promena samoglasnika važi samo za **du** — ihr i Sie nemaju promenu.

## Nepravilni imperativ

### sein

| Lice | Oblik |
|------|-------|
| du | **Sei** ruhig! |
| ihr | **Seid** ruhig! |
| Sie | **Seien Sie** ruhig! |

### haben

| Lice | Oblik |
|------|-------|
| du | **Hab** Geduld! |
| ihr | **Habt** Geduld! |
| Sie | **Haben Sie** Geduld! |

### werden

| Lice | Oblik |
|------|-------|
| du | **Werd/Werde** ruhig! |
| ihr | **Werdet** ruhig! |
| Sie | **Werden Sie** ruhig! |

## Razdvojivi glagoli u imperativu

Prefiks ide na kraj kao i u Präsensu:

```
aufmachen → Mach die Tür auf!
anrufen   → Ruf mich an!
aufstehen → Steh auf!
mitkommen → Komm mit!
```

### Jaki + razdvojivi

```
anfangen  → Fang an!       (a→ä samo u du Präsens, ali u imperativu nema promene za schwache prefixe)
einladen  → Lad ein!       (a→ä: Lädt ein → Lad ein — imperativ du bez Umlaut)
```

> Kod jakih razdvojivih u imperativu **du** — *a→ä* promena se **ne primenjuje**: `Fahr ab!` ne `Fähr ab!`

---

## Refleksivni glagoli u imperativu

Povratna zamenica ostaje:

```
sich setzen → Setz dich! / Setzen Sie sich! / Setzt euch!
sich beeilen → Beeil dich! / Beeilen Sie sich! / Beeilt euch!
sich anmelden → Melde dich an! / Melden Sie sich an!
```

---

## Ublažavanje — bitte

`bitte` čini zahtev učtivijim, može da stoji na više mesta:

```
Komm bitte!
Bitte komm!
Komm, bitte!
```

## Pregled — sva tri oblika

| Infinitiv | du | ihr | Sie |
|-----------|-----|-----|-----|
| kommen | Komm! | Kommt! | Kommen Sie! |
| lernen | Lern(e)! | Lernt! | Lernen Sie! |
| sprechen | **Sprich!** | Sprecht! | Sprechen Sie! |
| sein | **Sei!** | **Seid!** | **Seien Sie!** |
| sich setzen | Setz **dich**! | Setzt **euch**! | Setzen Sie **sich**! |
| aufstehen | Steh **auf**! | Steht **auf**! | Stehen Sie **auf**! |
