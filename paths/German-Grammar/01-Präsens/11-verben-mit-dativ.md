# Glagoli koji traže Dativ (Verben mit Dativ)

**Nivo:** A2–B2


Većina glagola traži **Akkusativ** za objekat. Ali postoji grupa glagola koja uvek traži **Dativ**.

Dativ → pitanje: **Wem?** (Kome?)  
Akkusativ → pitanje: **Wen/Was?** (Koga/Šta?)

---

## Dativ lične zamenice (podsetnik)

| Nominativ | Dativ |
|-----------|-------|
| ich | **mir** |
| du | **dir** |
| er | **ihm** |
| sie | **ihr** |
| es | **ihm** |
| wir | **uns** |
| ihr | **euch** |
| sie/Sie | **ihnen/Ihnen** |

## Posebna pažnja — gefallen

*gefallen* u srpskom odgovara "sviđa mi se" ali struktura je obrnuta:

```
Das gefällt mir.          → To se meni sviđa.   (Das = podmet!)
Die Stadt gefällt mir.    → Grad mi se sviđa.
Gefällt dir das Buch?     → Sviđa li ti se knjiga?
```

**Česta greška:**
```
~~Ich gefalle das Buch.~~     ✗
Das Buch gefällt mir.         ✓
```

---

## Posebna pažnja — fehlen

```
Du fehlst mir.            → Nedostaješ mi.
Er fehlt mir sehr.        → Jako mi nedostaje.
Was fehlt dir?            → Šta ti nedostaje? / Šta te boli?
```

---

## Posebna pažnja — gelingen / misslingen

Bezlični glagoli — podmet je uvek **es** ili infinitivna fraza:

```
Es gelingt mir.                    → Uspevam.
Es gelingt mir nicht zu lernen.    → Ne uspevam da učim.
Es gelingt ihr immer.              → Njoj uvek polazi za rukom.
```

## Glagoli koji mogu imati i Akkuzativ i Dativ

Mnogi glagoli imaju **dva objekta** — jedan u Dativu (kome), jedan u Akkuzativu (šta):

| Glagol | Srpski | Primer |
|--------|--------|--------|
| geben | davati | Ich gebe **dir** (Dat) ein Buch (Akk). |
| zeigen | pokazivati | Er zeigt **mir** (Dat) den Weg (Akk). |
| schicken | slati | Ich schicke **dir** (Dat) eine Nachricht (Akk). |
| schenken | poklanjati | Sie schenkt **ihm** (Dat) ein Buch (Akk). |
| erklären | objašnjavati | Er erklärt **mir** (Dat) das Problem (Akk). |
| bringen | nositi, doneti | Bring **mir** (Dat) Wasser (Akk)! |
| empfehlen | preporučiti | Er empfiehlt **mir** (Dat) ein Restaurant (Akk). |

**Red reči:** Dativ dolazi **pre** Akkuzativa.

```
Ich gebe dir das Buch.          → dir (Dat) + das Buch (Akk)
Ich gebe es dir.                → es (Akk zamenica) + dir (Dat)  ← zamenica ide ispred!
```

> Kad su oba objekta zamenice, **Akkuzativ zamenica** dolazi pre Dativ zamenice.

---

## Razlika glagol + Dativ vs glagol + Prepozicija

Pazi na razliku — isti glagol, drugačija struktura:

| | Primer | Srpski |
|--|--------|--------|
| **danken + Dativ** | Ich danke **dir**. | Zahvaljujem ti. |
| **sich bedanken bei + Dativ** | Ich bedanke mich **bei dir**. | Zahvaljujem ti se. |
| **antworten + Dativ** | Er antwortet **mir**. | Odgovara mi. |
| **antworten auf + Akk** | Er antwortet **auf die Frage**. | Odgovara na pitanje. |
| **glauben + Dativ** | Ich glaube **dir**. | Verujem ti (osobi). |
| **glauben an + Akk** | Ich glaube **an Gott**. | Verujem u Boga. |
