# Plusquamperfekt — Upotreba i veznici

**Nivo:** B1


Plusquamperfekt se gotovo uvek pojavljuje uz veznike koji označavaju **vremenski redosled**. Razumevanje konteksta ključno je za tačnu upotrebu.

---

## Vremenska linija: Plusquamperfekt vs Perfekt vs Präteritum

```
─────────────────────────────────────────────────────→ vreme

  [PLUSQUAMPERFEKT]      [PRÄTERITUM/PERFEKT]      [SADAŠNJOST]
  hatte gemacht          machte / hat gemacht
  war gegangen           ging / ist gegangen

  "bio sam uradio"       "uradio sam"               "radim"
  (starija prošla r.)    (novija prošla r.)
```

**Pravilo:** Kada su dve prošle radnje u vremenskom odnosu — starija ide u **Plusquamperfekt**, novija u **Präteritum** ili **Perfekt**.

---

## Veznici koji zahtevaju Plusquamperfekt

### nachdem — pošto, nakon što

*nachdem* **uvek** zahteva Plusquamperfekt u sporednoj rečenici (starija radnja), a Präteritum/Perfekt u glavnoj (novija).

```
Nachdem er gegessen hatte, ging er schlafen.
→ Pošto je pojeo, otišao je da spava.

Nachdem sie die Prüfung bestanden hatte, feierte sie.
→ Pošto je položila ispit, proslavila je.

Nachdem wir angekommen waren, suchten wir ein Hotel.
→ Pošto smo stigli, potražili smo hotel.
```

> Oba glagola u prošlosti, ali *nachdem* rečenica uvek ima Plusquamperfekt.

### als — kada (jednokratno, prošlost)

*als* s Plusquamperfektom naglašava da je radnja sporedne rečenice završena **pre** radnje glavne:

```
Als ich ankam, hatte er schon gefrühstückt.
→ Kada sam stigao/la, on je već bio doručkovao.

Als der Film begann, waren wir schon eingeschlafen.
→ Kada je film počeo, mi smo već bili zaspali.
```

### bevor — pre nego što

*bevor* + Präteritum/Perfekt, ali prethodna radnja u P.q.:

```
Bevor er ankam, hatte sie alles vorbereitet.
→ Pre nego što je stigao, ona je sve bila pripremila.

Bevor ich das gewusst hatte, machte ich Fehler.
→ Pre nego što sam to znao/la, grešio/la sam.
```

### bis — dok, sve dok (do trenutka)

Uz *bis* Plusquamperfekt se koristi kada se naglašava završenost radnje:

```
Er wartete, bis sie angekommen war.
→ Čekao je dok ona nije stigla.
```

## Poređenje: Plusquamperfekt vs Perfekt vs Präteritum

| Vreme | Primer | Srpski | Napomena |
|-------|--------|--------|----------|
| Präteritum | Er **kam** nach Hause. | Došao je kući. | Pisani jezik, naracija |
| Perfekt | Er **ist** nach Hause **gekommen**. | Došao je kući. | Govorni jezik |
| Plusquamperfekt | Er **war** schon nach Hause **gekommen**. | Već je bio došao kući. | Pre druge prošle radnje |

**Oba prikazana zajedno:**

```
Er hatte schon gegessen, als sie ankam.
→ Već je bio pojeo kada je ona stigla.

Präteritum:    ankam       (novija radnja)
Plusquamperfekt: hatte gegessen (starija radnja)
```

## Česte greške

### Greška 1: Upotreba Perfekta umesto Plusquamperfekta uz nachdem

```
✗ Nachdem er gegessen hat, ging er schlafen.
✓ Nachdem er gegessen hatte, ging er schlafen.
```

### Greška 2: Mešanje pomoćnog glagola

```
✗ Ich hatte nach Hause gegangen.
✓ Ich war nach Hause gegangen.       (gehen → sein)
```

### Greška 3: Zaboravljanje da P.II ostaje isti

```
✗ Ich hatte gefahrt.
✓ Ich war gefahren.                  (fahren → gefahren, sein)
```

### Greška 4: Red reči u sporednoj rečenici

```
✗ ..., dass er hatte das gegessen.
✓ ..., dass er das gegessen hatte.   (hatte/war uvek na KRAJU)
```

## Primeri — kratke priče

```
Ich war erschöpft, weil ich lange gearbeitet hatte.
→ Bio/la sam iscrpljen/a jer sam dugo radio/la.

Nachdem sie den Kurs abgeschlossen hatte, fand sie einen Job.
→ Pošto je završila kurs, našla je posao.

Als wir ins Kino kamen, hatte der Film schon angefangen.
→ Kada smo došli u bioskop, film je već bio počeo.
```
