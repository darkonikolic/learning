# Partizip II — Slabi glagoli (pravilni)

**Nivo:** A2


Slabi (pravilni) glagoli grade Partizip II po **fiksnom pravilu**: dodaju se prefiksi i nastavci bez promene korena.

---

## Osnovno pravilo

```
ge- + koren + -t

machen  → ge + mach + t  → gemacht
lernen  → ge + lern + t  → gelernt
kaufen  → ge + kauf + t  → gekauft
```

---

## Poseban slučaj: koren na -d ili -t

Umeće se **-e-** radi izgovora:

```
arbeiten  → ge + arbeit + et  → gearbeitet
reden     → ge + red + et     → geredet
warten    → ge + wart + et    → gewartet
```

| Infinitiv | Partizip II |
|-----------|-------------|
| arbeiten | gearbeitet |
| reden | geredet |
| warten | gewartet |
| antworten | geantwortet |
| kosten | gekostet |

---

## Glagoli na -ieren — bez ge-

Glagoli stranog porekla koji završavaju na *-ieren* **ne dobijaju ge-**:

```
studieren  → studiert
telefonieren → telefoniert
interessieren → interessiert
reparieren → repariert
```

| Infinitiv | Partizip II |
|-----------|-------------|
| studieren | studiert |
| telefonieren | telefoniert |
| reparieren | repariert |
| passieren | passiert |
| fotografieren | fotografiert |
| funktionieren | funktioniert |
| trainieren | trainiert |
| organisieren | organisiert |

---

## Nerazdvojivi glagoli — bez ge-

Glagoli s **nerazdvojivim prefiksima** (be-, er-, ver-, ent-, ge-, zer-, miss-, emp-) **ne dobijaju ge-**:

```
besuchen   → besucht     (ne: gebesucht)
erklären   → erklärt
vergessen  → vergessen   (jak, ali bez ge-)
verstehen  → verstanden  (jak, ali bez ge-)
bekommen   → bekommen    (jak, ali bez ge-)
```

| Prefiks | Primer | Partizip II |
|---------|--------|-------------|
| be- | besuchen | besucht |
| be- | bestellen | bestellt |
| er- | erklären | erklärt |
| er- | erlauben | erlaubt |
| ver- | verkaufen | verkauft |
| ver- | versuchen | versucht |
| ent- | entscheiden | entschieden |
| ge- | gehören | gehört |
| zer- | zerstören | zerstört |
| miss- | missverstehen | missverstanden |

---

## Razdvojivi glagoli — ge- između prefiksa i korena

Razdvojivi prefiks ostaje ispred, **ge-** se umeće između:

```
aufmachen   → auf + ge + mach + t  → aufgemacht
anrufen     → an + ge + ruf + en   → angerufen   (jak)
einkaufen   → ein + ge + kauf + t  → eingekauft
```

| Infinitiv | Partizip II |
|-----------|-------------|
| aufmachen | aufgemacht |
| einkaufen | eingekauft |
| ausfüllen | ausgefüllt |
| anmelden | angemeldet |
| abholen | abgeholt |
| aufräumen | aufgeräumt |
| zumachen | zugemacht |
| vorbereiten | vorbereitet |
| abreißen | abgerissen |
| anziehen | angezogen |
