# Mešoviti glagoli u Perfektu

**Nivo:** A2–B1

Partizip II mešovitih glagola: uzimaju **ge-...-t** (slabi obrazac) ali koren se menja.

---

## Konjugacija u Perfektu

Svi mešoviti glagoli idu sa **haben**.

**denken** · misliti · [haben] · `habe gedacht / hast gedacht / hat gedacht / haben gedacht / habt gedacht / haben gedacht`

**bringen** · doneti, nositi · [haben] · `habe gebracht / hast gebracht / hat gebracht / haben gebracht / habt gebracht / haben gebracht`

**kennen** · poznavati · [haben] · `habe gekannt / hast gekannt / hat gekannt / haben gekannt / habt gekannt / haben gekannt`

**nennen** · nazivati · [haben] · `habe genannt / hast genannt / hat genannt / haben genannt / habt genannt / haben genannt`

**rennen** · trčati (brzo) · [sein] · `bin gerannt / bist gerannt / ist gerannt / sind gerannt / seid gerannt / sind gerannt`

**brennen** · goreti · [haben] · `habe gebrannt / hast gebrannt / hat gebrannt / haben gebrannt / habt gebrannt / haben gebrannt`

**wissen** · znati · [haben] · `habe gewusst / hast gewusst / hat gewusst / haben gewusst / habt gewusst / haben gewusst`

**senden** · slati · [haben] · `habe gesandt / hast gesandt / hat gesandt / haben gesandt / habt gesandt / haben gesandt`

**wenden** · okrenuti · [haben] · `habe gewandt / hast gewandt / hat gewandt / haben gewandt / habt gewandt / haben gewandt`

---

## Partizip II — pregled

| Infinitiv | Partizip II | Napomena |
|-----------|-------------|---------|
| denken | ge**dacht** | nk → cht |
| bringen | ge**bracht** | ing → acht |
| kennen | ge**kannt** | e → a |
| nennen | ge**nannt** | e → a |
| rennen | ge**rannt** | e → a, sein! |
| brennen | ge**brannt** | e → a |
| wissen | ge**wusst** | i → u |
| senden | ge**sandt** | e → a |
| wenden | ge**wandt** | e → a |

> **rennen** jedini ide sa **sein** (kretanje).

---

## Primeri u rečenicama

```
Ich habe daran gedacht.        → Mislio/la sam na to.
Er hat die Blumen mitgebracht. → Doneo je cveće.
Ich habe ihn nie gekannt.      → Nisam ga nikad poznavao/la.
Das Haus hat gebrannt.         → Kuća je gorela.
Ich habe das nicht gewusst.    → Nisam to znao/la.
Sie hat sich an uns gewandt.   → Obratila nam se.
Er ist gerannt.                → Trčao je.
```
