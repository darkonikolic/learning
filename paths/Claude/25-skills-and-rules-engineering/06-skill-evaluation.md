# Skill evaluation

**Theme:** A Skill that “runs” but **produces shallow output** is debt—measure quality like any engineering component.

### Sample rubric dimensions (trim per Skill)

**Symfony architect Skill**

Ownership clarity  

Boundary sharpness  

Tradeoff substantiveness (not generic bullet salad)

**Ops debug Skill**

Hypothesis quality before action  

Rollback / safety posture explicitness

**Go backend Skill**

Simplicity vs cleverness balance  

Concurrency correctness honesty  

Failure ownership (timeouts, cancellation, idempotency hooks)

**LAB deliverable:** author `SKILL_EVALUATION_RUBRIC.md` (illustrative name) with **scoring columns** (e.g. 1–3) + mandatory **failure modes** (“Skill accepted work missing rollback note”).

Cadence: quarterly pass over top Skills updating rubric when platform evolves.

Tie to **EVALUATION** pillar in Engineering Template—close loop into Rule/Skill edits.

### Checklist

- [ ] Evaluations log **concrete counterexamples**—not only numeric scores.
