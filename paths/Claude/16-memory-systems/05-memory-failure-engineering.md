# Memory failure engineering

**Theme:** Memory systems degrade predictably—classify faults like any distributed hazard.

Representative failures:

Context **overload / noise domination** reducing effective comprehension  

Stale or mythic episodic overlays (“we already fixed”—but branch diverged)  

Critical **SPEC fragments forgotten** amidst summarization churn  

Mis-**retrieved** artefacts (nearby but wrong bounded context synonyms) sabotaging refactor confidence  

**Security-adjacent:** unintended secret echoes into durable summary stores demand aggressive redaction—not “helpful shorthand.”

Labs: engineer **bruised setups** ethically in sandboxes:

Overlong rolling recap lacking retrieval pointers  

Stale semantic bullet asserting retired architecture  

Mis-labeled SPEC path references

Observe assistant behaviour—expects **classification** rehearsal per incident into memory vs retrieval vs context hygiene buckets—not immediate patch improvisation without fault taxonomy.

Repair strategies include targeted re-ingestion bursts, rewriting overlay bullets, pinning authoritative artefact excerpts, escalating human reconciliation checkpoints.

### Checklist

- [ ] Each rehearsal ends with actionable **preventive structuring tweak**—not only narrative acknowledgement.
