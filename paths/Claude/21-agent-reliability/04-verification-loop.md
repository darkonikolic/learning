# Verification loop

**Theme:** Generated artefacts are **hypotheses** until verified—you own the loop comparing them to authoritative truth.

Workflow drumbeat internalised:

```
 GENERATE provisional output slice
           → VERIFY using independent artefacts (SPEC lines, tests, tool queries, infra plan)
                              → structured COMPARE divergence classification
                                                          → concise REPAIR pass
                                                                     → rerun VERIFY gates until closures or escalation triggers
```

**Practice arenas**

Symfony **refund flow** behavioural patch—replay acceptance scenarios & domain invariants mechanically.  

Go **payment worker** adjustment—simulate duplicate delivery traces / timeout traces adversarially.  

**Deploy workflow** artefacts—inspect diff vs approved manifest scope & RBAC realistically.

Mandatory lab heuristic: annotate **minimum three VERIFY steps** tying each major output—mix automated + manual checks ethically appropriate to maturity.

Danger: verification theatre—checking obvious constants while skipping integration edges—call out as anti-pattern journaling.

Discuss **verification ownership separation** from authoring persona when organisational maturity allows—parity with human code review philosophies.

Metrics mindset: escalating early defect capture shrinks catastrophic repair amplification later—qualitative journaling suffices initially.
