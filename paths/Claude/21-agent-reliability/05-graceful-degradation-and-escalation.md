# Graceful degradation + escalation

**Theme:** Healthy agent systems **narrow** temporarily rather than **collapse catastrophically**—until humans retake sharper control.

Representative perturbations requiring design:

Mandatory tool class (example **MCP** path) unreachable—routing to degraded doc-only rehearsal or ticketing stub instead of paralysis.  

**DB** partitioned read-only failover mode—Architect / Implement personas must constrain scope ethically.

Architect or model expresses **low confidence**—must trigger **human escalation** rather than low-quality autonomous completion masquerading as progress.

Operational macro arc:

```
 failure detected succinctly classified
           → attempt bounded automated FALLBACK modality
                             → escalate HUMAN stakeholder if escalation triggers hit
                                                             → CONTINUE on trimmed scope—or pause explicitly as valid outcome
```

**Degradation plan** artefact rehearsals include: degraded functionality statement, surfaced user-visible impact honesty, backlog items capturing deferred excellence.

Discuss **graceful degradation** ethics: narrower assistant operating envelope beats misleading fully-capable hallucinated answers.

Concurrency nuance: partial degradation interacts with retries—ensure combined strategy still honours global safety.
