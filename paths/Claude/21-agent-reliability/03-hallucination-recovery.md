# Hallucination recovery

**Theme:** Outputs can be plausible and **wrong**—treat hallucination-risk as operational failure mode with explicit **confidence** routing.

Recovery macro-pattern exercised:

```
 surface RESULT
        → VERIFY against specs / codebase / authoritative docs retrieval
                     → revise CONFIDENCE assessment candidly
                            → selective RETRIEVE sharper grounding—or ESCALATION if irreducible ambiguity
                                             → structured REPAIR of proposal or artefacts
                                                       → CONTINUE with verification rerun
```

**Practice rehearsals**

Symfony **CQRS** boundary claims must map to folders / handler registration reality—verification refuses decorative architecture fantasy.  

Go **distributed retry** statements must reconcile with deployed config flags—not aspirational folklore.  

**Terraform** assertions cross-check `terraform plan` semantics—not imagined resource shapes.

Mandatory lab cruelty: willingly supply **underspecified prompts** detecting susceptibility spikes—observe whether assistant elevates CONFIDENCE conservatively—or require human pause.

Confidence rubric prompts (adapt):

High: cited primary sources anchored verifiably shortly  

Medium: partial coverage—additional retrieval flagged explicitly  

Low / Stop: escalate or refuse speculative implementation until gap closed

Discuss **verification ownership**: another persona or scripted check—not self-attestation alone on high-impact paths.

### Checklist

- [ ] Confidence **downgrades** visibly when contradictions emerge mid-flow—not silent edits hoping nobody notices.
