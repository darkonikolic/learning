# Validation and verification loops

**Theme:** Outputs are **doubled-checked** deliberately — scepticism is methodological, not cynical.

### Vocabulary tightening

| Term | Plain meaning |
|------|---------------|
| **Verification** | “Built **as specified**?” (diff against SPEC/SUCCESS artefacts, structural integrity, contract symmetry). |
| **Validation** | “**Does behaviour match user / business intent** beyond mechanical compliance?” broader acceptance lens. |

### Loop you rehearse with Claude scaffolding

```
Spec alignment
   → Implementation slice
       → Automated / scripted verification pulses
           → Higher-order validation checkpoints
               → targeted repair choreography
                   → rerun until risks acknowledged or extinguished
```

## Lab choreography

Structured three-pass Claude collaboration:

1. Implementation draft **bounded**  

2. **Verification pass** referencing frozen checklist bullets  

3. **Repair** pass reconciling divergence inventory  

Echo logs / evidence snippets so regressions shrink next lap.
