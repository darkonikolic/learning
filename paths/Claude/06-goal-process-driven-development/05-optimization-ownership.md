# Optimization ownership

**Theme:** After baseline safety proofs, interrogate residual **risk • complexity • cost • performance**.

Stop asking Claude only “does it pass?” Prompt instead “**could this be materially better under stated ceilings?**”

### Practice hunts

| Track | Optimization lens prompts |
|-------|---------------------------|
| **Symfony** | aggregate cognitive load hotspots, needless synchronous coupling blobs |
| **Go** | worker concurrency reality vs allocation churn, backoff aggressiveness realism |
| **Ops** | deploy choreography minutes, flaky stage sensitivity, infra spend leakage |

### Lab rule cadence

Per meaningful task surface **≥ three** candidate optimizations categorized:

1. Complexity / readability debt trade  
2. Cost / infra sensitivity  
3. Latency / throughput envelope stretch  

Discard only with explicit rationale recorded.

### Concept tag recap

● **optimization ownership** — iterative trimming after truth surfaces  

### Checklist

- [ ] Optimisations tie back to measurable **SUCCESS CRITERIA** or budgets already declared upstream.
