# Cost thinking

**Theme:** Staff-level ownership includes **economics**: cloud bill, latency tax, cognitive load—and **AI usage** friction.

### Cost surfaces

**Claude / AI layer**

Estimated **token** spend per repeatable workflow—not vanity, trend watching.  

**Iteration tax** translating to calendar time delays.  

**Tool / MCP** call volume where vendors or rate limits sting.

**Ops / infra**

Cloud **compute/storage/network** hotspots Terraform can expose plainly. Idle environments, orphaned volumes, oversized clusters.

**Go runtime**

**CPU**, **memory**, **egress**—profile-driven; tie spend to code paths.

**Symfony / Laravel**

**Complexity / maintenance** cost: module entanglement enlarges every feature tax.  

Team onboarding time is a real cost—document simplification wins.

**Frontend (Vue / JS)**

Bundle weight, expensive re-renders, API chatty-ness—user-visible cost and infra cost.

### LAB

For each system you profile, add a **cost ownership** line: who watches the metric monthly, what threshold triggers review.

Connect to **OPTIMIZATION** and **EVALUATION** pillars—cost without quality guardrails is recklessness.
