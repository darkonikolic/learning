# Integration lab — observability contract

**Deliverable:** One-page **Observability Contract** for a service you own (real or synthetic):

1. SLI definitions + SLO targets + error budget policy (what freezes when budget low).  

2. Dashboard links / UIDs as code references.  

3. Top 5 alerts with owners + runbook anchors.  

4. Trace propagation map (which hops **must** create spans).  

5. Known blind spots + acceptance rationale.

**Pass bar:** A peer can **onboard to on-call** from this artifact alone in <30 minutes for happy & degraded paths.
