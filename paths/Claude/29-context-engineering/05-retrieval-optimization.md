# Retrieval optimisation for context engineering

**Theme:** Great context engineering **imports** selectively—question is **need**, not **inventory.**

Operational micro-pipeline disciplined:

```
 identify NEEDS absent from working packet
               → RETRIEVE candidate chunks (tiered indexes / paths)
                                          → RANK / score relevance honestly
                                                                     → FILTER noise & duplicates aggressively
                                                                              → COMPRESS if needed respecting protected fields
                                                                                          → INJECT deliberately + annotate sources
```

Excessive breadth (“just in case”) reintroducing flood
