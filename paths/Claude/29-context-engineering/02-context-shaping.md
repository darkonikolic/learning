# Context shaping

**Theme:** **Structured context** beats raw repository paste—anchors align thinking with invariant truth.

### Shaping scaffold (minimal packet)

```
 GOAL
  
 CONSTRAINT
  
 SPEC pointer + excerpt
 
 BOUNDARY / ownership statement
 
 RISK residues needing attention
 
 NFR / SLO touchpoints when relevant
```

**Practice arenas**

Symfony **payment aggregate** change—boundary + invariants excerpt first, handlers second.  

Go **distributed retry**—explicit layers (transport vs domain) typed before concurrency detail.  

**Ops incident**—symptom, blast hypothesis, immutable evidence excerpts—not entire log tails.

### LAB

Solve one problem twice:

**RAW** ingestion style (simulate historical bad habit) versus **SHAPED** packet using template—compare subjective **quality**, **repair iterations**, and **token estimates** honestly.

Discuss **risk**: shaping must not strip **safety negatives** (“never dual-write”) for brevity.
