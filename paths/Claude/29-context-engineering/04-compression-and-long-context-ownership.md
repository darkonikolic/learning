# Compression + long-context ownership

**Theme:** Compression is **selective truth preservation**—never synonymous with forgetting invariants quietly.

Avoid shipping **entire conversation histories** verbatim into fresh sessions—elevate distilled **constraints, SPEC excerpts, ownership lines, authoritative decisions.**

### Compression macro pipeline

```
 RETRIEVE candidate sources
           → COMPRESS respecting protected verbatim zones (IDs, limits, cryptographic constraints)
                                   → VALIDATE compressed packet still satisfies Template acceptance checks
                                                                   → INJECT consciously—never stealth-append forgotten layers later
```

### Long-context pathology rehearsal

Stale dialogue dominating fresh reasoning  

Buried authoritative SPEC drowned by chatter  

Stale operational snapshot misguiding infra actions

Mitigations:

Explicit **checkpoint packets** rewriting canonical mini-spec each stable milestone  

Rolling **ownership + risk** headings immune to summarise-away unless consciously edited  

Temporal tags (“true as-of commit/deploy id”) guarding ageing statements
