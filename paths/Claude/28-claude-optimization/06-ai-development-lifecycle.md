# AI development lifecycle

**Theme:** Participation threads **every** lifecycle phase—thin silo tooling fails staff expectations.

Integrated macro chain:

```
goal / OKR linkage
    → SPEC shaping
          → ARCHITECT slice
                → IMPLEMENTATION + tests
                      → REVIEW gates
                            → SECURITY assurances / threat delta
                                  → OPS readiness + deploy rehearsal
                                        → Incident learning feedback
                                              → SPEC / ADR evolution
```
Assistants augment **everywhere disciplined** — never bypass approvals or threat surfaces silently.

Discuss **verification optimisation**: automate cheap checks escalating human focus to subtle classes only.

Discuss **workflow optimisation**: standard transitions between personas / Skills reduce token waste rehearsing scaffolding.

Discuss **accuracy**: Retrieval + SPEC anchoring tighter reduces hallucination repair loops.
