# AI platform thinking — Claude Optimization framing

## Phase framing — Claude Optimization (“Faza 11”)

**Staff note:** Treat this as **infrastructure**, not “a smarter tab.” Optimise **tokens, context, workflows, processes, quality gates, verification, and cost** with explicit tradeoffs—not vibes.

**Units in this folder:** `01`–`08` (topic order only).

### Mindset pivot

| Weak framing | Strong framing |
|--------------|----------------|
| AI solves isolated tasks faster | **AI platform** lifts **whole-team** speed, consistency, safety, reuse |
| “We use Claude” | “We operate **RULES**, **Skills**, retrieval, memory, approvals, measurement” |

Target capabilities you **design**, not stumble into:

**AI coding platform** • **AI architecture workflow** • **AI review workflow** • **AI ops workflow** • **AI knowledge platform**  

Across **Symfony**, **Go**, **Ops/IaC**, **DB**, **frontend** estates you actually run.

### Optimisation compass (never optimise one blindly)

Tune for **Quality**, **Speed**, **Cost**, and **Accuracy / grounding**—accept explicit tension; document sacrifices.

Weekly themes weave: **token** + **context** efficiency, **workflow** + **process** shape, **quality** + **verification** tightening, dollar and minute **cost** honesty.

### Final Claude Platform Template — living system blueprint

| Pillar | Role |
|--------|------|
| **RULES** | Non-negotiables; style + safety rails. |
| **SKILLS** | Procedures with inputs → steps → outputs. |
| **MEMORY** | Where durable truth lives vs chat ephemera. |
| **RETRIEVAL** | How facts load without flooding context. |
| **SECURITY** | Threat + AI-abuse posture tied to approvals. |
| **APPROVAL** | Gate matrix for explosive actions. |
| **EVALUATION** | KPIs + rubrics; experiment logs. |
| **ARCHITECTURE** | Requirements → boundaries → ownership → failures → tradeoffs → scale → observability. |
| **OPS** | Incident → detect → evidence → repair → rollback discipline. |
| **REVIEW** | Correctness, security, maintainability, performance, ownership—not “LGTM skim.” |
| **TEAM SCALE** | Multi-dev onboarding, drift control, bottlenecks at 15+ people clarity. |

**Checkpoint mantra:** you **engineer platforms** coders onboard into—not hero prompts per senior.
