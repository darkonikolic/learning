# AI ops platform

**Theme:** Incident path is reproducible infra behaviour—not improvisational adrenaline.

Operational macro workflow:

```
 incident declared
       → DETECT consolidating signals & scope
               → HYPOTHESIS short list ranked
                             → logs + metrics corroborate / falsify swiftly
                                             → bounded REPAIR choreography
                                                             → rollback readiness reaffirmed continually
                                                                     → CONTINUE with observability deltas watched
```

Author **`ops-incident`** (name illustrative) **Skill**: inputs (symptom, environment, recent changes)—outputs (timeline scaffold, hypotheses, evidence checklist, guarded next steps).

Mandatory synthetic drills (**LAB**):

Worker timeouts  

Growing queue backlog  

Slow relational queries cascading latency

Measure **speed** (**MTTR** proxy) improving as Skill + **RULES** mature—paired with accuracy of hypothesis quality.

### Checklist

- [ ] Every drill ends with documented **preventive backlog** linkage—not only closure applause.
