# Team scale thinking

**Theme:** Designing for yourself fails at **fleet scale** (~15 engineers). Institutionalise drift control.

Pain vectors:

Skill copy drift (**Skill drift**)  

RULE wording divergence (**rule drift**)  

Knowledge staleness unnoticed (**knowledge drift**)  

**Approval bottlenecks** when only one heroic senior clears platform PRs forever

Mitigations brainstorming:

Monthly **RULE / SKILL diff council** rotating ownership  

Mandatory **evaluation sampling** auditing assistant traces anonymised-but-actionable  

Onboarding playbook ensuring consistent **evaluation + approval** etiquette  

Throughput metrics on approval queue SLA—escalate process not blame individuals blindly
