# Logs ownership

**Theme:** Presence of an ERROR line is worthless without **context tapestry**: locality, causal ordering, multiplicity, prelude signals.

Elevate interrogation pillars:

```
 WHERE (service / shard / replica / cron lane)
 WHEN (timeline resolution beyond single line)
 HOW MANY (burst vs steady trickle preceding alert)
 SEQUENCE (antecedent WARN / sluggish dependency stamp)
 Anchors → timestamp • request_id • trace_id • correlation keys
Pattern mining → rolling window frequency shift
```

Anti-pattern forbid list for labs: Immediate **restart** fetish before **structured log narrowing** exercised.
