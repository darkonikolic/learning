# Routing ownership

**Theme:** Capability inventory answers “who **could** act.” Routing answers “who **ought** act now.”

Practice contrasts:

Go **worker timeout** alarm storm route sketch:

Possible mis-route: drowning Architect prematurely without Ops signal capture. Prefer **Ops ingest → structured evidence packet → Architect only if behavioural hypothesis demands design pivot → Reviewer on risky infra tweak proposals**.

Symfony **aggregate** behavioural regression route:

Architect tightens invariant narrative before Implementer churn—never routing Implementer solitary when ambiguity remains structural.

Produce **routing plan** artefacts per rehearsal:

Trigger conditions  

Responsible agent personas  

Mandatory inputs / artefacts they must refuse without  

Termination / handoff signalling clarity

Discuss **topology fork types**: deterministic pipeline vs conditional branch vs parallel fan-out reunited at merge QA gate ethically.

Delegation anti-pattern: symmetrical round-robin “everyone touches everything” defeats ownership economy—call it out ruthlessly during labs.
