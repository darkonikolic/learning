# Git MCP

**Theme:** Evolution narrative beats static snapshot—“what changed?” often answers “why fragile now?” faster than speculative architecture essays.

Mandatory perspectives when harnessing Git capabilities:

Structured **diff comprehension** spanning domain + infra  

**Commit archaeology** clustering related behavioural shifts—not line noise obsession  

Selecting **rollback / revert anchors** realistically (ordering conflicts honoured)  

**Migration ownership pairing DB schema evolution commits** with runtime expectations

Symfony exercise: analyse **refund flow** divergence across merges; narrate behavioural risk succinctly.

Go counterpart: quantify **optimization diff** hotspots—benchmark tie-back optional unless performance thread active.

Assistant output must summarise **Δ behaviour**, latent **risk classes**, pragmatic **rollback** options—not only patch content.
