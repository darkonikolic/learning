# Integration lab — full stack + Claude platform experiments

Composite pain bundle across **Symfony**, **Go**, **MySQL**, **Terraform**, **Docker**, **Kubernetes**, plus your **Claude platform** (retrieval, memory, Rules, Skills, agent topology).

Representative problems:

**Retrieval** sluggish or imprecise on large tree  

**Agent routing** mis-assigning ownership slices  

**Incident** workflow elongated / opaque  

**Token** spend bloated on recurring task classes

### Required experiment chain (use Template end-to-end)

```
 PROBLEM quantified
       → HYPOTHESIS sharp
             → A/B (or controlled sequential) CHANGE
                   → KPI capture
                         → RESULT + REGRESSION CHECK
                               → DECISION logged (adopt / iterate / revert)
```

### Measure aggregate story

Quality gain vs regression drag  

Cost / token / calendar speed deltas  

Stability signals (incidents, rollback frequency) moving favorably or not
