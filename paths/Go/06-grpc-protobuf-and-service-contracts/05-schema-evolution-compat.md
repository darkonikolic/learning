# Unit 5 — Schema evolution & compatibility anxieties (most valuable long-run sub-skill)

## Failure-class awareness

Dangerous impulses:

```
delete field numbering rashly rewriting history
reuse field numbers injecting silent mis-decoding nightmares
rename without dual-read transitional strategies in advanced production (preview conceptually—not mandatory full exercise now)
```

Reconciliation habits:

```
reserve retired numbers / names explicitly when removing
never recycle identifiers
paired deployment ordering sensitivity honesty
backward compatible additive changes preferred default
```
