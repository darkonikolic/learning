# Weekly drill schedule — minimum viable reps

> One scenario cluster per week. Complete its minimum reps. Log done/skipped — no essay required.

---

## Design principle

Attempted scenarios must outrun fresh pages skimmed. Reading new material gives the feeling of progress. Drilling old material produces the actual progress.

Minimum viable session: **10–15 minutes**. If you have 30 — extend the hard items, don't add a new cluster.

---

## Weekly cycle (4-week rotation)

### Week 1 — Message classification + observer labelling

**Goal:** classification reflex under 2 seconds, observer-stable log from at least one real contact.

| Day | Activity | Time | Log |
|---|---|---|---|
| Mon | Drill Set A — [Message Classification](../06-situation-literacy/03-message-classification-drill.md) | 15 min | Done / Skipped |
| Wed | Drill Set B — same drill | 15 min | Done / Skipped |
| Thu–Fri | Fill [Observer daily log](../03-observer-loop/02-observer-daily-log.md) after one real contact | 5 min | Done / Skipped |
| Sun | Weekly observer log scan — count observer-stable vs impulse | 5 min | Done / Skipped |

**Week 1 minimum:** 2 drill sessions + 1 observer log entry.

---

### Week 2 — Communication under pressure: pause and structure

**Goal:** 2-second gap before first word, no filler syllables, 3-sentence limit per turn.

| Day | Activity | Time | Log |
|---|---|---|---|
| Mon | Solo spoken reps — read 10 prompts from Set B aloud, pause 2 sec before each answer | 10 min | Done / Skipped |
| Wed | Partner or voice-recorded session — 6 prompts, answer in 1–3 sentences max, then stop | 15 min | Done / Skipped |
| Thu–Fri | Apply in one real interaction — note where silence felt uncomfortable | — | Note: ________ |
| Sun | Review: how many times did "...and another thing" or filler appear this week? | 5 min | Count: ________ |

**Week 2 minimum:** 1 solo rep session + 1 application in real contact.

---

### Week 3 — Sustained pressure and compound accusations (Drill Set C)

**Goal:** refuse premises cleanly without mirroring insult, route compound accusations to single focus.

| Day | Activity | Time | Log |
|---|---|---|---|
| Mon | Drill Set C — classify and route all 10 items | 15 min | Done / Skipped |
| Wed | Spoken triad practice on 6 items: **refuse premise → boundary sentence → behavioural pivot** | 15 min | Done / Skipped |
| Thu–Fri | If a difficult message arrives this week: classify before replying. Log it. | — | Done / Skipped |
| Sun | Note: which item type in Set C was hardest? Add to next week's hard-item list. | 5 min | Item: ________ |

**Week 3 minimum:** 1 classification session + spoken triads on at least 3 items.

---

### Week 4 — Integration and reset loop

**Goal:** run a full simulated interaction from start (observer pre-state) through contact through post-contact log.

| Day | Activity | Time | Log |
|---|---|---|---|
| Mon | Morning protocol (stress digit + action sentence) — log it | 3 min | Digit: ________ |
| Mon–Fri | Evening review [template](../11-reflection-evening-loop/02-evening-review-template.md) — 3 questions daily | 5 min/day | Streak: ___/5 |
| Wed | Simulated heavy contact: partner reads from drill set C + D (create your own hard set), you respond live with: observe → route → 1–3 sentences → stop | 20 min | Done / Skipped |
| Fri | Post-contact observer log from the simulated session | 5 min | Done / Skipped |
| Sun | Month review: which skill moved most? What's the hardest remaining cluster? | 10 min | Skill: ________ |

**Week 4 minimum:** 5-day evening review streak + 1 full simulated session.

---

## Quarterly recalibration

After 4 weeks, answer:

1. Which drill felt routine? (evidence of skill building)
2. Which drill still felt uncomfortable every time? (priority for next cycle)
3. Has any real-world scenario type NOT appeared in drills? (add it to a custom set)

Adjust the next cycle based on gaps, not on what felt good to do.
