# Observer fabric — Body · Impulse · Narrative braid

## What this settles

You learn to perceive **distinct channels simultaneously** rather than collapsing into whatever story catastrophe offers first: body signals, impulses to flee/snipe/ghost, explanatory narratives—all observed without instantaneous fusion (**“I equals the indictment”** disappears as default).

## Story / lens

Courtroom-ish rooms downgrade rhetorical virtuosity celebrating **steady affect** + truthful minimal wording. Observation ≠ moral sentencing yourself — it inventories channels so physiology + procedural reset prime, then **[interpretive hygiene separates inference from datum](../04-cognitive-distortion-literacy/)**, before you choose communication manoeuvres (**order**: regulate → distortion check → corridor clarity → linguistic tactic). Companion reflections live **[after-contact notes](02-after-talk-reset-and-review.md)** + **[FAST](../01-operational-stance/03-fast-playbook.md)**.

## Moves

• ~**15 skim labels** aloud: prompt list (solo/partner flash) ⇒ answer first dominant channel **Body** / **Impulse** / **Story**—no argumentative defence of diagnosis.

• **Two-minute vigil** seated silently: each diversion craving (thumb scroll / snack phantom / triumphant courtroom fantasy) ⇒ whisper inward **Impulse** then breath anchor—not hunting zero urges, hunting visible catches frequency.

• **Partner sting ladders** escalate neutral ⇒ sharp interrogatives one-at-a-time: answer **minimal safe clause** practising notice→ exhale→word chain; afterward log exactly **three tokens** `{observer-stable / impulse / slipped-on-____}`.

## Ordering with regulation + tactics

Observe → physiology / honest postpone if needed → **[interpretation sanity pass](../04-cognitive-distortion-literacy/)** → select **[communication manoeuvre](../05-communication-under-pressure/)** — never reversing that stack during heat.
