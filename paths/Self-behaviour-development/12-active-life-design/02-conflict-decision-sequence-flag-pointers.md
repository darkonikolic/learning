# Conflict decision sequencing and flag cues

## What this settles

Internalise a short pipeline: **assess importance / risk / meaningful goal → pattern class → engage / minimal / distance / exit → silent midstream checkpoint**—without mistaking autopilot (people-pleasing, counterattack) for strategy.

Pair with proactive energy framing when habitual avoidance masquerades as peace: **[Building-life offensive overview](01-building-life-offensive-layer-overview.md)**.

## Story / lens

The sequence runs classification first, then situation-type routing, then discrete stance, then conversation hygiene—**mid-conversation audits** flag slow bleeds early. When recurring conflict scripts flare, tighten routing with neighbouring communication and literacy sheets; when the habitual error is **always** choosing battle instead of building alternatives, lean harder on offence-layer option work—not louder engagement by default.

## Moves

Twenty scenarios voiced aloud: final word **only** mode tag **ENG / MIN / DIS / EX** first pass—second pass one tactical sentence each.

Live contentious calls: silent vibrate cue every interval—each buzz asks *still toward purpose? draining faster than informing?* If no → downgrade mode.

Across a deliberate month, catch **early unnecessary engagement** at least twice weekly before it metastasises.
