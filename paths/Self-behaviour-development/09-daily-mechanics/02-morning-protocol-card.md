# Morning protocol card — daily operational start

> Complete before first heavy contact of the day. Entire sequence: under 5 minutes.

---

## Sequence

**1. Triple breath (30 seconds)**

Three slow breaths, each one longer than the previous. On the third exhale: shoulders drop, jaw unclenches.

Not meditation. Not a ritual you perform beautifully. A mechanical reset.

**2. Stress digit (15 seconds)**

Pick a number 1–5 right now:

```
1 = rested, clear, no background noise
2 = slightly tired or something low-grade running
3 = elevated — some stress present, manageable
4 = high load — external pressure, sleep deficit, conflict active
5 = overwhelmed or dysregulated — system is hot
```

Say the number aloud. Write it if you have a log.

> If 4 or 5: today is a managed day, not a performance day. Adjust commitments accordingly. Do not pretend the number is lower.

**3. Single reachable action (60 seconds)**

Complete this sentence:

> "Today, one bounded thing I will do is ________."

Rules for the sentence:
- Observable: you can verify by end of day whether it happened
- Reachable: possible with current energy level
- Not abstract: "be calm" is not it. "Send that message before lunch" is.

Write it down or say it aloud. Both work. The act of stating it matters more than the medium.

---

## Daily log (optional, high-value if maintained)

```
Date:              ________
Stress digit:      ________
One action:        ________
Completed by EOD:  Yes / No / Partial
```

**Streak target:** complete this before first serious contact on 7 consecutive days. After that it becomes background. Before that — track it mechanically.

---

## Trigger map

| If stress digit is... | Then... |
|---|---|
| 1–2 | Normal day, full engagement available |
| 3 | Useful signal. Note what's running. No action change needed. |
| 4 | Lighten scheduled commitments where possible. No difficult communications without preparation. |
| 5 | Reschedule non-urgent high-stakes interactions. Protect recovery window. |
