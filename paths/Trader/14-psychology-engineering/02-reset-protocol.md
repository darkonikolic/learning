# Reset protocol — tiered escalation, no live renegotiation

> Decide the ordering here, in cold state. When activated hot, follow the tier exactly — no skipping, no bargaining.

---

## Tilt detection checklist

Check if 2 or more of these are true right now:

- [ ] Clicked faster than normal in the last 10 minutes
- [ ] Skipped a journal field to get into a trade sooner
- [ ] Felt strong pull to re-enter immediately after a loss
- [ ] Thought "I just need to get my money back"
- [ ] Widened a stop after it was set
- [ ] Angry, frustrated, or restless — not neutral
- [ ] Haven't eaten or moved in 3+ hours

**2 or more checked → activate Tier 1 immediately.**

---

## Reset tiers

### Tier 1 — Pause (2 checks triggered)

1. Close order entry window (not the platform — just the order panel)
2. Stand up, move away from the screen
3. Set a timer: **15 minutes minimum**
4. During the pause: no charts, no news, no market talk
5. Return check: retake tilt checklist. If 0–1 checks — resume. If 2+ — go to Tier 2.

### Tier 2 — Flatten and stand down (3+ checks, or repeated Tier 1)

1. Close or flatten all open positions
2. Log: "Tier 2 activated — ________ [brief reason]"
3. Remainder of session: no live trading
4. Can use time for: replay review, journaling past trades, reading, walking
5. Before tomorrow's session: complete weekly review template, even if mid-week

### Tier 3 — Multi-day halt (daily cap hit + tilt, or same mistake 3× same day)

1. Flatten all positions
2. Log: "Tier 3 — halted ________"
3. No live trading for ________ full calendar days (decide now: ___ days)
4. During halt: replay only, no real capital, write post-mortem using template below
5. Return criteria: post-mortem complete AND reviewed by ________ (self cold-state review, or a trusted trading peer)

## Boredom substitutes (pre-approved list)

When boredom pulls toward random entries, choose from this list instead:

- [ ] Replay last 5 missed setups — grade them
- [ ] Write one sentence adding to the experiment backlog
- [ ] Review monthly mistake leaderboard
- [ ] Walk ________ minutes
- [ ] ________
- [ ] ________

Add your own. The list must exist before the boredom hits — not improvised during it.

---

## Loss acceptance pre-trade ritual

Before confirming any order — state this aloud or write it in the pre-trade journal field:

> "This trade risks ________ EUR / ________ R. I accept this loss if the setup fails. My thesis is ________ and my invalidation is ________."

This is not a superstition. It reduces shock paralysis and post-loss impulsive re-entry by pre-loading the expected loss as a cost of doing business.
