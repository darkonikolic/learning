# Unit 05 — Processes and services

## Theme

What runs on the system and how it is supervised.

## LabEx

Finish:

- **Process Utilization**

## Udemy — Linux Administration Bootcamp

Sections:

- Process management  

## Commands to practice

`ps`, `top`, `kill`, `jobs`, `systemctl`

## Exercise

```bash
ps aux
top
kill <PID>
systemctl status ssh
```

## Topic checklist

- Processes and PIDs  
- Foreground / background jobs  
- Services and **systemd** unit interaction at a basic level  

## Learning outcome

You can list processes, identify a runaway job, stop it safely, and check whether a service is active.
