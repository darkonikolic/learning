# Phase one — Linux / CLI foundations (resources & environment)

Phase one ends when you work in a Linux shell **without hesitation**, grasp a **server-oriented** mental model, and perform **basic administration** comfortably.

## Core goal (not “memorize Linux”)

You want a **low-friction CLI**, working knowledge of the **filesystem**, **users / groups / permissions**, **processes**, **packages**, **logging**, **systemd**, **SSH**, **text tooling**, **Bash basics**, and a **Linux server mindset**.

## Primary resources

### LabEx (Linux Journey–style Linux learning)

**Site:** [https://labex.io/](https://labex.io/)

Complete these tracks end‑to‑end:

- Grasshopper  
- Text-Fu  
- User Management  
- Process Utilization  
- Package Management  
- Filesystem  
- Networking Nomad  
- Init / Systemd  
- Logging  

**Extra emphasis:** Grasshopper, Text-Fu, Networking Nomad.

### Udemy — Linux Administration Bootcamp

**Course:** [Linux Administration Bootcamp](https://www.udemy.com/course/linux-administration-bootcamp)

Focus only on:

- Linux fundamentals  
- Filesystem  
- Permissions  
- Users  
- Process management  
- Package management  
- Networking sections  
- Logging  
- systemd  
- SSH  
- cron  

**Defer for now:** LDAP, Kerberos, deep LVM, heavy enterprise storage topics.

## Practice environment (required)

- **Ubuntu VM** (or equivalent you control)  
- **Terminal every day**  
- A **local practice folder**, e.g.:

```bash
mkdir training
cd training
```
