# Oscp+ / PEN-200 — program overview and learning model

This trace is for building a solid base in **Linux**, **networks**, **web security**, **Windows enterprise**, **Active Directory**, and practical **systems analysis**. The focus is not only on tools, but on **how systems behave**, how **misconfiguration mistakes** typically appear, and how issues can be **recognized**, **reproduced**, and **remediated** responsibly.

Topics are organized in **phases** as numbered **`paths/Oscp+/<NN>-area/`** trees: Linux foundations → Networking → introductory cyber foundations → Web/backend/auth → systematic Burp tooling → Windows / AD enterprise context → **Kali-based toolchain familiarity** → **deep enumeration methodology** → **guided lab ladders toward PEN-200**. Earlier blocks deliberately feed later ones.

Stress is on **hands-on work**:

| Practice surface | Examples |
|------------------|----------|
| Local labs | VMs, scripted exercises |
| Network analysis | Captures and logs you own authorization to inspect |
| Reproduction | Controlled repro of misconfigurations and failures |
| Documentation | Structured notes and findings |

The outcome is **not** memorizing individual tools alone, but cultivating **technical thinking**, repeatable **methods**, and the ability to **analyze** complex systems safely.

This is **long‑horizon** study — steady daily practice beats rushing material. Aim for depth of understanding, not completion speed alone.
