# Unit 10 — PEASS auditors for configuration archaeology

Use selective [linPEAS / WinPEAS](https://github.com/peass-ng/PEASS-ng) runs **only on throwaway VMs** you own—not production.

Harvest categories: odd service identities, brittle scheduled tasks, interesting environment variables, Linux SUID artefacts, Windows mis-set ACL pockets—then write defensible remediation notes **for lab closure**.
