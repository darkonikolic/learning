# Unit 12 — Symfony-flavoured ASVS / API security deepening

Cross-read authoritative sources—verify current revision levels yourself:

[OWASP ASVS](https://github.com/OWASP/ASVS) (architecture & verification guidance) paired with **[OWASP API Security Top 10](https://owasp.org/API-Security/)**.

Focus lenses relevant to heavyweight PHP backends:

- Broken object-level authorisation (**BOLA**)  
- Authentication fragilities & token replay classes  
- Excessive truthful data exposure camouflaged as completeness  
- Server-side unsafe request routing classes  
- Systemic misconfiguration debt vs component-only blame deflection  

Map each lens to illustrative defensive backlog items—not buzzword tagging alone.
