# Unit 11 — End-to-end methodology rehearsal

Practice narrating—not executing blindly:

```
Fingerprint listeners → corroborate service roles → pivot protocol class (HTTP / SMB / LDAP / Kerberos hypotheses) → gather bounded evidence packs → formulate validation experiment → summarise documentation bundle
```

Emphasise **documentation rhythm** contemporaneous—not retroactive scribbling devoid of fidelity.
