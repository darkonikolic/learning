# PEN-200 Enrollment and Coursework Guide

## Enroll

offsec.com/courses/pen-200

## Lab Time Options

| Duration | Recommended For |
|----------|-----------------|
| 30 days | Already solving PG Hard consistently, fast learner |
| 60 days | Consistently solving PG Medium without hints |
| 90 days | Still building speed, want buffer time |

If in doubt, pick 90 days. Unused time is wasted money; too little time forces a repurchase.

## What You Get

- Video + PDF course materials
- Lab network with 70+ machines
- Challenge labs (Active Directory sets, practice exam environments)
- One exam attempt included

## Exam Format

- Duration: 24 hours active (23h45m), then 24 hours to write and submit report
- Machines: 3 standalone + 1 AD chain (DC + 2 clients)
- Pass score: 70+ points out of 100
- Metasploit: allowed on one machine only (not on the AD chain)

## Lab Strategy

Use the same methodology you built on TryHackMe/HTB/PG — don't try to learn new techniques during lab time. Labs are for applying what you know, not learning it for the first time.

```
Week 1-2:  Complete course materials (video + PDF)
Week 3+:   Lab machines — minimum 5 per week
Final week: Challenge labs + practice exam environment
```

## What Not to Discuss Publicly

- Exam machine names
- Specific vulnerabilities found on exam machines
- Any details that would help someone pass without the skill

Violating OffSec's exam policy results in exam invalidation. Community: r/oscp on Reddit, TJ_Null Discord, official Kali Linux Discord at offensive-security.com.

## Report Requirements

- Must include: IP, hostname, proof screenshot, exploitation steps, remediation
- Format: OffSec-provided template (available on exam page)
- Submission: upload PDF within 24 hours of exam end
