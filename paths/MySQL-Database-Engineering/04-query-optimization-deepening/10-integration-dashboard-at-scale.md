# Unit 10 — Integration lab (dashboard KPIs on wide fact tables)

Assume large user and order populations; define dashboard metrics: revenue aggregates, top cohorts, growth counters, refund rates.

For each metric set: index rationale, join choreography, plan snapshot, cost narrative.

Interview synthesis: `EXISTS` vs `IN`, join vs subquery, filesort, temps, N+1 avoidance, optimiser surprises, star projection penalties, full scans when acceptable.
