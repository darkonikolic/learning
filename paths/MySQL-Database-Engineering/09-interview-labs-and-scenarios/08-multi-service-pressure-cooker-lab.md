# Unit 08 — Full-stack pressure rehearsal (timed architect drill)

Synthetic stack narrative: Symfony API → MySQL → Redis auxiliaries → asynchronous Go-flavoured workers—collectively alleged to buckle under accelerating order ingestion with CPU hotspots, lethargic backup windows, SLA-breaching dashboards, measurable replica divergence.

Spend roughly ninety self-timed minutes:

1. List clarifying questions you would escalate to ambiguous stakeholders/product owners/SRE counterparts.
2. Enumerate prioritised hypotheses with observable signals capable of falsifying each.
3. Outline containment versus structural remediation arcs with sequencing honesty.
4. Surface trade-offs (financial, organisational, correctness, staleness allowances) without collapsing into techno-optimistic hand-waving.
